# job-hunt

데이터는 공개 레포 https://github.com/gabury1/newbie-job-hunt 에 있고 매일 아침 갱신된다. 레포를 내려받지 않고 웹에서 읽는다.

1. https://raw.githubusercontent.com/gabury1/newbie-job-hunt/main/AGENTS.md 를 먼저 읽는다. 파일 구조와 지킬 것이 거기 있다.
2. 공고 고르기 · 지원 준비 · 회사 비교 · 마감 정리의 순서와 규칙은 https://raw.githubusercontent.com/gabury1/newbie-job-hunt/main/.claude/skills/job-hunt/SKILL.md 를 읽고 따른다.
3. 레포 안 경로를 읽을 때는 앞에 `https://raw.githubusercontent.com/gabury1/newbie-job-hunt/main/` 을 붙이고, 경로의 빈칸은 `%20` 으로 바꾼다.
4. 공고 목록은 `postings.jsonl` 한 파일에 다 있다. 공고 노트와 회사 노트는 고른 공고의 것만 읽는다.
