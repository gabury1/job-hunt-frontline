## 지원 자격

### 필수 경험과 역량

- 클라우드(AWS) 또는 시스템/인프라/보안 관련 실무 경험 1년 이상(또는 이에 준하는 완성도 높은 프로젝트 경험)
- Linux/Unix CLI 환경에 익숙함
- 네트워크 기본 지식(TCP/IP, HTTP/HTTPS, DNS, CIDR, Subnet)을 갖춤
- Docker 컨테이너의 기본 개념을 이해하고, 로컬 또는 클라우드 환경에서 컨테이너화된 애플리케이션을 다뤄 본 경험
- AWS 핵심 리소스(EC2, VPC, IAM, S3 등)의 구성과 역할을 이해함
- 인프라 · 보안 엔지니어링에 대한 열정과 복잡한 인프라 구조를 빠르게 학습하려는 의지
- 개발 · 운영 등 유관 부서와 원활하고 능동적으로 커뮤니케이션하는 역량

### 졸업 · 학업 조건

- 학력: 학사 이상
- 졸업 시점, 근무 가능 시기, 병역, 어학 조건은 공고에 없다.

### 우대사항

- AWS Organizations, Transit Gateway 등 멀티 계정/네트워크 환경 경험
- ECS(Fargate) 기반 컨테이너 오케스트레이션 및 GitHub Actions CI/CD 구축 · 운영 경험
- 기존 레거시 서비스를 컨테이너 환경으로 전환(마이그레이션)한 경험
- Python, Bash 등으로 단순 반복 업무를 스크립트로 자동화한 경험
- 백엔드 개발 경험 또는 ISMS-P 등 정보보호 관리체계 인증 대응 경험
