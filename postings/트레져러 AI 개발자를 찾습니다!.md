## 팀이 하는 일

> 공시·리서치·시세·거래 데이터를 LLM이 읽고 쓸 수 있는 형태로 연결하고, 그 위에서 에이전트가 애널리스트나 운용역의 작업을 대신 수행하게 만드는 것이 우리 일입니다.

트레져러는 증권사, 자산운용사, 금융 미디어, 보험·재보험사가 실제 업무에 쓰는 금융 데이터 AI 레이어를 만든다. 지금 풀고 있는 문제는 아래와 같다.

- 수만 건의 DART 공시·증권사 리포트·PDF 표를 LLM이 정확히 인용할 수 있는 단위로 파싱·청킹·임베딩하는 파이프라인
- 금융 질의에서 "그럴듯한 답"과 "맞는 답"을 구분하는 평가셋 구축과 자동 평가 (LLM-as-judge의 한계 포함)
- MCP 기반 툴 수십 개를 붙인 에이전트가 수치 하나 틀리지 않고 멀티스텝 분석을 끝내게 만드는 오케스트레이션과 가드레일
- 토큰 비용·레이턴시·정확도 사이의 트레이드오프를 실제 고객 트래픽 기준으로 튜닝하는 일

## 지원 자격

### 필수 경험과 역량

- Python으로 동작하는 것을 혼자 끝까지 만들어 본 경험
- 스스로 문제를 정의하고 해결책을 검증해 본 경험. 어떤 지표로 "됐다"고 판단했는지 설명할 수 있어야 함
- AI 코딩 도구가 만든 코드가 왜 맞고 왜 틀리는지 읽어 낼 수 있음
- 처음 보는 API 문서를 읽고 며칠 안에 프로토타입을 만들어 본 경험
- Git 브랜치·PR 흐름으로 협업 가능

### 졸업 · 학업 조건

- 학력 무관(직행 표기)
- 경력 무관

### 우대사항

- RAG·에이전트를 만들어 보고 "잘 안 됐던 부분"을 설명할 수 있음
- 임베딩 모델·청킹 전략·리랭킹을 비교 실험해 본 경험
- LLM 출력 평가(정확도, 환각, 인용 검증)를 자동화해 본 경험
- 금융 데이터의 구조(공시, 재무제표, 시장 데이터)에 호기심이 있음

## 제출 서류와 지원 방법

- 지원하는 곳: 트레져러 채용 페이지(라운드HR)의 「지원하기」
- 처음에 내는 서류: 이력서 하나(필수). 파일 업로드나 링크 중 하나로 내고, 파일은 최대 80MB다.
- 지원 양식 입력: 이름 · 이메일 · 연락처(모두 필수), 약관 동의(필수), 개인정보 필수 항목 수집/이용 동의(필수), 개인정보 선택 항목 수집/이용 동의(선택)
- 포트폴리오 제출란과 자기소개 문항은 없다.
- 전형 중에 내는 증빙 서류: 공고에 없음
