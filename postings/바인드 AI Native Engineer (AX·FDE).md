## 지원 자격

### 필수 경험과 역량

- AI 코딩 에이전트로 무언가를 끝까지 만들어 배포하거나, 다른 사람이 실제로 써 보게 한 경험
- 웹과 앱이 어떻게 동작하는지 설명할 수 있음
- 새로운 AI 모델이나 도구가 나오면 먼저 써 보고, 결과를 다른 사람에게 설명할 수 있음
- 일을 맡기기 전에 범위와 완료 조건을 정하고, 에이전트에게 맡길 일과 직접 판단할 일을 나눔
- AI가 틀렸던 순간과 그것을 알아챈 방법을 구체적으로 말할 수 있음
- AI가 쓴 코드를 읽고 각 부분이 왜 필요한지 설명할 수 있음
- 기술적인 내용을 다른 직군 동료도 이해할 수 있는 말로 풀어 설명함
- 운영 데이터나 비용이 걸린 일 앞에서는 먼저 물어봄

### 졸업 · 학업 조건

- 학력: 무관(직행 표기). 회사 공고 원문에는 학력 · 졸업 시점 · 병역 · 어학 조건이 없다.
- 근무 가능 시기: 공고에 없음

### 우대사항

- 하네스(CLAUDE.md, AGENTS.md, 스킬, 훅)를 직접 구성한 경험
- 여러 에이전트 세션을 동시에 운용하고, 세션 사이에 작업을 인계한 경험
- 이미지 생성 모델(이미지 생성 API, ComfyUI 등)로 결과물을 만든 경험
- SQL이나 로그로 문제를 수치로 확인한 경험
- 패션이나 커머스에 대한 관심
