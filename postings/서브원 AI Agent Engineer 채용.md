> 특정 Agent Framework의 사용 경험보다는 Agent의 구조와 실행 원리를 이해하고, 과제의 요구사항에 맞는 Framework·SDK·Model·Tool을 선택하여 실제 업무 가치를 만들어낼 수 있는 엔지니어링 역량을 중요하게 생각합니다.

## 제출 서류와 지원 방법

- 지원하는 곳: 홈페이지 지원(캐치의 「채용홈 바로가기」로 들어간다). 서브원 채용 사이트 주소는 공고에 없다.
- 처음에 내는 서류: 지원서와 포트폴리오(필수)
- 지원서 작성 안내: 아래 내용 중 1개 이상을 골라 구체적인 경험을 작성한다. 단순한 LLM 활용 경험보다 아래 내용을 구체적으로 쓰는 편이 좋다고 안내한다. 글자 수는 공고에 없다.
  - 직접 설계 · 개발한 AI Agent의 구조와 본인의 역할
  - 현업의 문제를 AI Agent 과제로 정의하고 해결한 경험
  - Agent가 사용하는 Tool/API 및 외부 시스템 연계 방식
  - 사용한 Agent Framework/SDK와 해당 기술을 선택한 이유
  - RAG · Memory · MCP · Multi-Agent 등을 적용한 경험
  - Claude Code · Codex · Cursor 등 AI Coding Agent를 실제 개발에 활용한 사례
  - Agent의 실패 사례와 원인 분석 및 개선 경험
  - PoC 이후 실제 사용자 또는 현업 업무에 적용한 경험과 정량적 · 정성적 성과
- 전형 중에 내는 증빙 서류: 공고에 없음
