## 지원 자격

### 필수 경험과 역량

- C/C++ 프로그래밍 역량(Erlang 이면 더 좋음)
- Linux 환경에서의 소프트웨어 개발 경험
- 3GPP 표준, 5G architecture, NGAP · NAS 같은 packet core 프로토콜 지식
- network virtualization, containerization, cloud-native 기술에 익숙함
- version control(Git), issue tracking(Jira), CI/CD 파이프라인 사용 경험
- 문제 해결 · 커뮤니케이션 역량과 팀 환경에서 효과적으로 일하는 능력

### 졸업 · 학업 조건

- Computer Science, Electrical Engineering 또는 관련 분야 학사(Bachelor's) 또는 석사(Master's) 학위
- 공고 대상은 New Grads(신입)다

### 우대사항

- microservices, containers, Kubernetes 등 cloud-native 기술과 아키텍처 경험
- NFV(network function virtualization) · SDN(software-defined networking) 기술 경험
- 네트워크 보안 원칙과 프로토콜 지식
- 5G service-based architecture 와 network slicing 에 익숙함
