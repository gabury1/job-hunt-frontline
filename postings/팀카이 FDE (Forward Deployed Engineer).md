## 팀이 하는 일

> 모든 기업이 AI를 통해 탁월한 고객 경험을 제공할 수 있도록 돕는다.

팀카이는 고객사의 고객센터를 AI로 혁신하는 AI Agent 운영 플랫폼 KaiCX를 만들고, FDE는 Agent Engineer가 만든 프레임워크로 한 고객사의 에이전트를 끝까지 만들어 운영 지표를 움직이는 역할이다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 고객사 에이전트 빌드: Agent Engineer의 프레임워크와 제품 기능을 기반으로 담당 고객사의 도메인 · 시스템 · 정책에 맞는 에이전트 1 instance를 구축한다. Agent PM과 합의된 사양 그대로 코드와 설정으로 옮긴다 | 외부 API 연동 · 정책 인용 · intent 분류 · supervision · 가드레일 설정 · 사람 상담사 핸드오프 정책 |
| 고객사 현장 출장: 첫 진입 시점에는 며칠간 고객사의 CS 운영을 옆에서 관찰하며 문의 유형 · 정책 · 예외 케이스 · 톤을 흡수한다. 운영 단계에서도 큰 정책 변경이나 어려운 케이스가 생기면 현장에서 운영팀과 함께 해결한다 | |

## 지원 자격

### 필수 경험과 역량

- LLM 기반 제품을 직접 빌드해 본 경험, 또는 빌드를 배워 가며 6개월 안에 1개 고객사 instance를 출시할 수 있다는 자기 확신과 학습력
- 외부 API를 직접 연동해 단순 응답을 넘어 실제 작업을 수행하는 에이전트를 구현해 본 코딩 역량(혹은 그에 준하는 실무 코딩 경험)
- 새로운 도메인을 빠르게 흡수하는 학습력, 고객사 현장에 며칠 들어가 운영팀의 일을 옆에서 보고 핵심 패턴을 뽑아내는 관찰력
- 실제 대화 로그 · 운영 데이터를 매일 들여다보고 실패 케이스에서 원인을 찾아 가설로 옮기는 분석력
- 고객사 실무 담당자 · 운영팀과 직접 대화하며 합의를 만드는 커뮤니케이션 역량, 출장과 현장 협업에 거부감 없음
