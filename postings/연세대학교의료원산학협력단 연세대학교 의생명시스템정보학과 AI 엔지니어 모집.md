## 지원 자격

### 필수 경험과 역량

- R, Python으로 프로젝트를 완성해 본 경험(개인/팀/학교 프로젝트 모두 포함)
- LLM API 또는 오픈소스 LLM을 이용해 무언가를 직접 만들어 본 경험
- RAG의 기본 개념 이해(임베딩, 벡터 검색, 청킹이 무엇이고 왜 필요한지)
- Git을 이용한 버전 관리 경험

### 졸업 · 학업 조건

- 학력 무관

### 우대사항

- 의료 분야 데이터 처리 경험(의료 텍스트, 임상 데이터, 논문/가이드라인 등)
- R, Python 이외 Java, JavaScript, C 등 여러 프로그래밍 언어 경험
- 벡터 DB 사용 경험(FAISS, Chroma, Qdrant, pgvector 등)
- 에이전트(Agent), Tool calling, 에이전틱 RAG 등에 대한 관심 또는 시도 경험
- 오픈소스 LLM 서빙 경험(vLLM, Ollama, TGI 등)
- Docker 컨테이너 활용 능력과 OS(Windows, Linux)에 대한 기본 지식
- AWS/GCP 등 클라우드 인프라 운영 경험
- Database 관리 경험(SQL Server, PostgreSQL 등)
- 새로운 기술을 스스로 찾아 학습하고 시도하는 태도
- 공고 소개 글에 적힌 인재상: 빠르게 바뀌는 LLM 생태계를 즐기며 따라감, 불확실한 문제를 일단 만들어 보며 풀어 가는 실행력, 실험 결과를 솔직하게 공유하고 안 되는 것도 배움으로 정리함, 연구자 · 비개발자와도 편하게 소통함
