## 팀이 하는 일

Product Division 의 mAsh Cell 은 CCTV 영상을 AI 로 분석하는 매장 방문객 분석 솔루션 매쉬(mAsh)를 만들고, 여러 기업 고객이 방문객 데이터를 계속 활용하도록 API 와 집계 · 재처리 시스템을 개발하고 운영한다. Product Owner 상우님, Backend Engineer 승리님과 함께 일하며, 담당 영역에 따라 Core Cell · Web Platform Cell · Infra Cell 과 협업한다. 현대자동차 · LG전자 · 스파오 등이 매쉬를 쓰고 있고, 2023년 대비 2026년 예상 매출은 약 5배, 누적 투자유치액은 130억원 이상이다.

입사 초기에는 주요 고객 지표와 데이터 흐름, 기존 API · DB 구조를 파악하고 작은 버그 수정과 성능 개선을 맡는다. 이후 집계 · 재처리 · 분석 파이프라인 연동과 반복 업무 자동화를 담당한다. 담당 업무는 입사 후 리드와 정하고, 1개월차 원온원과 온보딩 리뷰가 있다.
