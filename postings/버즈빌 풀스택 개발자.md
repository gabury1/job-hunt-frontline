## 팀이 하는 일

> 어제보다 나은 나, 어제보다 나은 팀을 지향합니다.

버즈빌은 리워드 광고 플랫폼이다. 광고주를 위한 광고 상품 · 운영 시스템과 매체사를 위한 수익화 지면 · SDK를 모두 자체 개발한다. 엔지니어들은 광고 할당, 리워드 적립, 정산, 셀프서브 광고 플랫폼처럼 MAU 1,500만 규모의 트래픽을 처리하는 시스템을 만든다. 엔지니어는 한 도메인에 고정되지 않고, 비즈니스 임팩트가 큰 프로젝트에 합류한다.

## 담당할 업무

참여하는 프로젝트에 따라 담당 도메인은 달라진다. 다만 아래 업무는 공통으로 수행한다.

| 광고 운영 · 셀프서브 제품의 풀스택 개발: 광고 운영 대시보드, 셀프서브 광고 플랫폼, 어드민 등의 화면과 API · 비즈니스 로직을 설계하고 구현 | TypeScript, Go, Python |

업무는 백엔드 개발이 중심이다. 다만 제품 상황에 따라 프론트엔드(어드민 · 대시보드 등)를 포함한 풀스택 개발로 범위가 넓어질 수 있다. 회사는 백엔드 기반을 갖추고 필요한 기술 영역으로 유연하게 확장할 수 있는 사람을 찾는다.

개발 환경은 아래와 같다. 참여하는 프로젝트에 따라 일부 다를 수 있다.

- Backend: Go, Python(Django), MySQL, DynamoDB, Redis, Elasticsearch, Kafka
- Frontend(풀스택 업무 시): TypeScript, Vue.js, React / Next.js
- Infra / DevOps: AWS, Kubernetes, Airflow, GitHub Actions, Argo CD, Gitploy
- Monitoring: Datadog, Grafana, Prometheus, Loki, Sentry
- Collaboration / AI Tools: Linear, Jira, Confluence, Slack, GitHub, Claude Code, Cursor, Codex

원티드 공고 정보의 기술 스택 칸에는 PyTorch, ML 이 적혀 있다. 그러나 본문의 업무와 개발 환경에는 두 기술이 나오지 않는다.

## 지원 자격

### 필수 경험과 역량

- 경력 무관: 신입부터 지원할 수 있다. 학위 과정의 연구 · 프로젝트, 인턴, 개인 프로젝트처럼 역량을 보여 줄 수 있는 경험이면 충분하다
- Go, Python 등 하나 이상의 서버 프로그래밍 언어로 동작하는 서비스를 만든 경험
- TypeScript/JavaScript 기반의 웹 프론트엔드(Vue, React 등 프레임워크 무관)를 개발한 경험
- MySQL 등 관계형 데이터베이스를 사용한 경험
- 화면부터 API · 데이터까지 제품 하나를 끝까지 만든 경험 (개인 · 팀 프로젝트 포함)
- 복잡한 문제를 구조적으로 분석하고 기술적으로 풀어낸 경험 (실무 · 연구 · 프로젝트 모두 포함)
- 다양한 직군(PM, 디자이너, 다른 엔지니어 등)과 원활하게 소통하고 협업하는 역량
- AI 도구를 적극적으로 활용하고, 이를 통해 생산성을 높이는 데 관심이 있음

광고 도메인 경험은 없어도 된다고 적혀 있다. 공고는 문제를 탐구하고 해결하는 태도를 더 중요하게 본다.

- 전문연구요원으로 복무할 수 있어야 한다. 아래 둘 중 하나에 해당해야 한다

  - 현재 전문연구요원으로 복무 중이며 병무청 전직 요건을 충족함

### 우대사항

- 실서비스 운영: 인턴 · 프로젝트 등에서 실제 사용자가 있는 웹 서비스를 배포 · 운영한 경험
- 프론트엔드 심화: 상태 관리, 렌더링 성능 최적화, 컴포넌트 설계 등을 고민한 경험
- API 설계: REST · GraphQL · gRPC 등으로 프론트엔드와 백엔드 사이의 인터페이스를 설계한 경험
- 클라우드 · 컨테이너: AWS 등 클라우드 환경이나 Docker · Kubernetes를 사용한 경험
- 데이터 저장소: Redis, DynamoDB 등 NoSQL 저장소를 사용했거나, 데이터 특성에 맞는 저장소 선택을 고민한 경험
