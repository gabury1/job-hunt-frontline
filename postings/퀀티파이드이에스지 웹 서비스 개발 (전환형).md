## 팀이 하는 일

퀀티파이드이에스지(QuantifiedESG, QESG)는 기업의 ESG 공시와 탄소 관리 업무를 소프트웨어와 컨설팅으로 돕는 회사이다. 지속가능경영보고서 발간, ESG 데이터 수집, 온실가스 산정, 기후 · 자연 리스크 분석, 공급망 평가 서비스를 하나의 플랫폼인 QESG Core로 묶고 있으며, 고객사는 계정 하나로 ERT · DMS · GHG(Carbon) · Climate-Risk·TNFD · Assessment 앱을 모두 쓴다. 고객사의 여러 사업장 담당자가 많은 양의 데이터를 입력 · 검토 · 제출하는 서비스라서 데이터 정합성, 권한, 변경 이력이 특히 중요하다고 공고는 밝힌다.

## 담당할 업무

| 서비스 기능 개발 참여(프론트엔드·백엔드) | |

| 테스트 코드 작성과 버그 수정 | |

이 포지션에서 경험할 수 있는 일로 공고는 다음을 든다.

- 수천 개 셀을 다루는 스프레드시트형 입력 화면의 성능 개선
- 앱 사이 데이터 연동과 공통 계정 플랫폼(QESG Core) 개발
- AI 에이전트를 서비스 기능으로 붙이는 일(변경 전후 비교, 사람의 승인 뒤 반영)

신규 서비스는 Kotlin·Spring Boot와 Vue(Nuxt)로 개발하고, 일부 레거시 서비스를 함께 운영한다. 공고에 적힌 기술 스택은 다음과 같다.

- 백엔드: Kotlin, Spring Boot, Spring Data JPA, JDBC, Flyway, Python(FastAPI, SQLAlchemy·Alembic), PostgreSQL, Redis
- 프론트엔드: TypeScript, Vue 3(Nuxt), React, Tailwind CSS, Handsontable, Storybook
- AI: Claude·OpenAI·Gemini API, Pydantic AI, RAG(Voyage 임베딩, BM25 키워드 검색)
- 인프라·모니터링: AWS(ECS, RDS, S3, CloudFront, SQS, CloudWatch), Terraform, Docker, GitHub Actions, Jenkins, Sentry
- 레거시: Python(Flask), MySQL, JavaScript

## 지원 자격

### 필수 경험과 역량

- Java·Kotlin/Spring 또는 JavaScript·TypeScript/Vue로 웹 애플리케이션을 직접 만들어 본 경험(개인·팀 프로젝트 포함)
- SQL과 관계형 DB의 기본 개념에 대한 이해
- Git으로 협업하거나 프로젝트를 관리해 본 경험
- AI 코딩 에이전트(Claude Code, Codex, Gemini CLI 등)를 써 본 경험
- 본인이 만든 코드를 설명할 수 있음

공고는 에이전트가 만든 코드를 검토하고, 근거를 갖고 채택하거나 버리며, 최종 결과를 책임질 수 있는 사람을 찾는다고 밝힌다. 또한 AI로 빠르게 만드는 것에 그치지 않고, 만든 코드를 이해하고 검증하는 습관을 가진 사람을 찾는다고 적었다.
