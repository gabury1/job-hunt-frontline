## 팀이 하는 일

> LG AI연구원 EXAONE Lab에서 AI Agent의 데이터 생성과 강화학습을 위한 대규모 Sandbox Execution Infrastructure를 만들어가는 여정에 함께 하실 분을 찾고 있습니다.

AI Agent 가 실제 소프트웨어 환경에서 다양한 작업을 수행하고 학습할 수 있도록 대규모 실행 환경을 안정적이고 효율적으로 제공하는 인프라를 만든다. Agent 의 역할과 Task 가 빠르게 늘어나면서 기존 Sandbox 시스템의 운영뿐 아니라 새로운 환경과 기능을 계속 개발한다.
