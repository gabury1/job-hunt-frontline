## 팀이 하는 일

> 아이와 함께 하는 삶이 더욱 행복하도록

무무즈는 부모의 하루를 더 가볍고 의미 있게 만들기 위해 시작된 키즈&패밀리 라이프스타일 플랫폼이다. 2020년에 런칭한 뒤 2025년에 연간 흑자를 달성했고, 이제 일본 시장으로 사업을 넓혀 가고 있다. 백엔드 팀은 커머스 운영을 받치는 사내 도구와 외부 시스템 연동을 맡는다. 공고는 CEO 인터뷰(https://zdnet.co.kr/view/?no=20221207165143)와 무무즈웨이(https://mooomooz.notion.site/2c03462e56f6803e8f86cea413e25a83?source=copy_link)를 읽어 보라고 권한다.

- Database / Messaging: Amazon Aurora (MySQL), MongoDB, Redis, AWS SQS / SNS
- Infra / DevOps: AWS (ECS, EC2, Lambda, S3 등), Docker, Bitbucket Pipelines 기반 CI/CD, ELK 기반 로그 모니터링
- 협업 및 개발 도구: Jira, Bitbucket, Slack, AI 코딩 도구 (Claude Code, Codex 등)
