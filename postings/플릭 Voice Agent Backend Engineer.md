## 팀이 하는 일

> 견고한 추상화를 유지하면서도 빠르게 출시할 수 있는 백엔드를 함께 만들어갈 분을 찾고 있습니다.

백엔드 팀은 vox.ai의 모든 음성 에이전트가 작동하는 기반 시스템을 만들고, 사용자가 대시보드에서 클릭 한 번으로 만든 에이전트가 실제 전화를 받기까지 거쳐 가는 모든 레이어를 책임진다. 매주 새로운 기능을 출시하고, 모델 생태계는 분기마다 판이 뒤집히는 환경이다.

## 지원 자격

### 필수 경험과 역량

- 프로덕션 백엔드 시스템을 설계·운영한 경험 3년 이상
- 확장성 · 신뢰성 · 동시성을 고려한 API와 분산 시스템 설계에 본인만의 기준이 있음
- 관계형 데이터베이스의 내부 동작 원리를 이해하고, 성능과 정합성을 함께 고민한 경험
- 비동기 처리 · 메시지 큐 · 이벤트 드리븐 아키텍처를 활용한 시스템 설계 경험
- 빠르게 변하는 요구사항 속에서 견고한 추상화와 출시 속도 사이의 균형을 잡는 능력

### 졸업 · 학업 조건

- 컴퓨터 공학 전공 혹은 그에 준하는 전공 및 지식
- 학력 무관 (직행 표기)

### 우대사항

- LLM 기반 애플리케이션 또는 에이전트 시스템을 설계·운영한 경험
- Langfuse 등 LLM 관측성 도구로 프로덕션 LLM 시스템을 운영한 경험
- 벡터 데이터베이스를 활용한 RAG 또는 시맨틱 검색 구현 경험
- 실시간 양방향 통신이나 멀티테넌트 아키텍처 설계 경험
- AI 코딩 도구를 적극 활용해 실제 작동하는 서비스를 빠르게 만든 경험
- 직접 스타트업을 창업하거나, 1인 개발로 서비스를 론칭해 운영한 경험
- 초기 시리즈 A·B 단계 스타트업에서 0→1 또는 1→n 구간을 경험함
