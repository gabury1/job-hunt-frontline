## 팀이 하는 일

> “비즈니스 임팩트를 기술로 설계하고, 서비스의 성장을 함께 만들어 갈 서버 개발자를 찾아요.”

토스가 새롭게 시작하는 온라인투자연계금융업 비즈니스를 운영할 자회사로, 출범을 준비하며 토스가 쌓아 온 사용자 경험과 기술로 새로운 금융 시장을 만들어 갈 예정이다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 대출 제품의 신규 기능을 확장성과 안정성을 고려해 설계하고 개발한다 | |
| 대출실행, 원장, 추심, 인증 등 대출자와 투자자 양쪽을 아우르는 금융시스템을 만든다 | |
| 정합성 검증, 모니터링, 장애 대응 체계를 갖춰 서비스가 안정적으로 운영되도록 한다 | |
| 유저의 목소리를 직접 듣고, 문제를 빠르고 유연하게 해결한다 | |

토스에서 사용하는 기술은 Kotlin, Spring · MySQL, MongoDB, Redis · ElasticSearch, Kafka 다.

## 지원 자격

### 필수 경험과 역량

- 최소 1년 이상의 실무 경험
- 금액과 상태의 높은 정합성이 요구되는 시스템을 설계하고 운영한 경험
- 고가용성의 확장 가능한 시스템을 설계하고 운영한 경험
- 복잡한 업무 규칙을 단순하고 일관된 구조로 정리하고, 정책 변화에 유연하게 대응하는 역량
- 요구사항 구현에 그치지 않고 현업과 함께 문제와 정책을 정의하는 역량
- 장애를 직접 겪고 원인 분석부터 재발 방지까지 해결한 경험
- 서비스에 애착을 갖고 「내 서비스」라는 마음으로 일함
- 개발하며 얻은 인사이트를 공유하고 기술적인 도전을 즐김

### 졸업 · 학업 조건

- 학력 무관

### 우대사항

- 테스트 인프라나 Mock Server를 구축한 경험
- 금융 규제와 컴플라이언스에 대한 이해, 또는 거버넌스를 설계한 경험
- 외부 파트너사, 금융기관과 연동하는 시스템을 개발한 경험

## 제출 서류와 지원 방법

- 지원하는 곳: 토스 채용 사이트 공고의 「지원하기」로 지원한다
- 처음에 내는 서류: 공고에 없음(유의사항에 「이력서 및 제출 서류」라는 말만 있다)
- 전형 중에 내는 증빙 서류: 공고에 없음

## 유의사항

- 이 포지션으로 입사하면 토스가 새롭게 시작하는 온라인투자연계금융업 비즈니스를 운영할 자회사에 소속된다. 해당 법인은 현재 출범을 준비하고 있다.
- 본 포지션은 최소 1년 이상의 실무 경험이 있는 사람을 찾는다.
- 이력서 및 제출 서류에 허위 사실이 발견되거나 근무 이력 중 징계사항이 확인될 경우, 채용이 취소될 수 있다.
- 토스 내규에 따라 채용금지자 또는 결격사유 해당자는 채용이 취소될 수 있다.
- 서버 개발자 (Server Developer) 포지션은 전형 과정에서 국문, 영문 명칭을 함께 사용한다.
- 문의는 토스 채용 사이트의 「채용팀에 문의하기」로 한다.
