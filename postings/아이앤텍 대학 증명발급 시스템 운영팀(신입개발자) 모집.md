## 팀이 하는 일

(주)아이앤텍은 2000년에 설립된 회사로, 26년간 대학 증명발급 1등 플랫폼 써트피아(Certpia)를 운영하고 있다. 사용자에게 편리한 증명발급 서비스를 제공하기 위해 플랫폼을 계속 업그레이드하고 있으며, 운영팀은 이 플랫폼을 개발 · 유지보수하면서 대학 전산 · 학사 담당자를 지원한다. 회사는 사원수 50명 이하의 중소기업(비상장)이고, 업종은 솔루션·SI·CRM·ERP다.

## 지원 자격

### 필수 경험과 역량

- 언어: PowerBuilder, Java
- 프레임워크: Spring MVC / Spring Boot
- DBMS: Oracle, MS-SQL, MariaDB
- 리포팅 툴: JasperReports, 클립리포트, 오즈리포트
- 기타: 기본적인 서버·네트워크 운영 지식
- 문제 해결 능력과 커뮤니케이션 능력
- **자격: 정보처리기사 자격증 필수**
- 모집요강의 스킬 칸에는 다음 기술이 따로 적혀 있다: JAVA, MySQL, OracleDB, Python, Spring, Spring Boot, ASP.NET CORE, Microsoft SQL Server, 전자정부표준프레임워크, 정보처리기사 자격

### 졸업 · 학업 조건

- 학력: 대학졸업(2,3년) 이상, 초대졸 이상
- 경력: 신입 (모집요강의 지원자격 칸에는 「신입·경력 (2년이상)」으로 적혀 있다)
- 모집 인원: 상세요강에는 본사 운영팀(신입개발자) 1명, 모집요강에는 2명으로 적혀 있다

- 컴퓨터공학 관련 전공 (우대전공: 소프트웨어개발전공, 컴퓨터소프트웨어 · 정보통신전공, 정보통신공학)
- 관련 자격증 보유(정보처리기사, 정보처리기능사)
- 교육기관 시스템 개발 경험
- 웹 서비스 개발 관련 프로젝트 경험
- 팀 협업 프로젝트 경험
- 다양한 교육 프로그램 참여 경험
