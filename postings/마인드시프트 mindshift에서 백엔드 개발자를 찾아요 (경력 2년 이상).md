## 팀이 하는 일

> mindshift는 블록체인 기술로 사용자에게 더 나은 금융 서비스 경험을 제공하는 것을 목표로 해요.

국내에서 합법적으로 가상자산을 취급할 수 있는 가상자산사업자(VASP) 신고를 마친 기업으로, ISMS 인증과 FIU 신고 수리를 바탕으로 가상자산 커스터디(수탁) 서비스를 운영하며 이제 커스터디를 중심으로 가상자산 금융 서비스를 넓혀 가려 한다. 입사 후 중심은 Java / Spring Boot / MySQL 기반의 기존 커스터디 플랫폼이고, 여기에 새로운 금융 상품 · 기능을 붙이고 입출금 · 보관 · 이전이 안전하게 돌아가게 만드는 일이 주 업무다.
