## 팀이 하는 일

> 디노티시아 Data 그룹은 벡터 데이터가 생성·저장·검색·확장되는 전 과정을 책임지며, AI가 단기 추론을 넘어 장기 기억과 의미 기반 검색을 수행할 수 있는 기술적 토대를 구축하고 있습니다.

Vector Database Engineer 는 수십억 규모의 벡터 데이터를 효율적으로 저장하고 검색하는 고성능 시스템을 만들어, 차세대 AI 솔루션의 장기 기억 및 검색 기능을 담당하는 대규모 벡터 데이터베이스를 연구 · 개발한다. 회사는 벡터 데이터 연산 가속기 'VDPU' 를 기반으로 고성능 벡터 데이터베이스 'SEAHORSE(씨홀스)' 를 선보이고, LLM 파운데이션 모델 'DNA' 와 엣지 디바이스 'MNEMOS(니모스)' 를 만드는 장기기억 인공지능 전문기업이다.
