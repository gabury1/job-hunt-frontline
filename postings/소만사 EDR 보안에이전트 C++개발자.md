## 팀이 하는 일

소만사는 1997년에 설립된 매출액 570억, 사원수 360명 규모의 회사로, 재무안정성 상위 1%, 22년 연속 흑자, 27년 무차입경영으로 고용노동부에서 선정한 재무구조가 탄탄한 강소기업이다. Privacy-i EDR 엔진은 엔드포인트의 프로세스, 파일, 네트워크 등에서 발생하는 실시간 이벤트를 분석해 이상 행위와 악성코드를 탐지하며, 최근에는 YARA, Sigma 등 최신 위협 인텔리전스 탐지 룰을 적용한 시그니처/비시그니처 통합 분석 엔진으로 진화하고 있다.

- C++11 이상의 Modern C++ 및 OS 하부 구조(Windows API, Linux System Call 등)를 제어하는 고성능 시스템 레벨 프로그래밍을 집중적으로 연구하고 개발한다.
- 안정성을 보장하면서 시스템 자원 사용을 최소화하는 저부하·고가용성 프레임워크 설계, 대규모 텔레메트리 데이터 처리 기술, 다양한 OS(Windows, Linux, macOS)를 아우르는 크로스 플랫폼 보안 모듈도 함께 연구한다.
