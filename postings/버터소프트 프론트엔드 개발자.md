## 팀이 하는 일

> 우리 회사의 정체성은 더 좋은 제품을 고객에게 전달하는 데 있다고 생각합니다.

버터소프트는 2024년 2월에 설립된 소프트웨어 개발 전문 에이전시이다. 외주 프로젝트와 자체 서비스 · 솔루션을 함께 개발하며, 기획과 디자인과 기술을 연결해 사람들이 실제로 사용하는 제품을 만든다. 회사는 AI 활용을 장려하지만, 사람이 쓴 코드와 AI가 생성한 코드를 같은 기준으로 읽고 코드 리뷰를 이어 간다고 밝힌다.

## 지원 자격

### 필수 경험과 역량

- 문제를 이해하고 원인을 추적하며 더 나은 해결 방법을 찾아가는 개발 과정 자체에 흥미와 보람을 느낌
- JavaScript와 웹의 기본 동작을 이해하고, 코드를 읽으며 실행 흐름을 파악하고 필요한 부분을 수정할 수 있음
- 익숙하지 않은 문제도 관찰한 사실을 바탕으로 가설을 세워 확인하고, 근거에 따라 자신의 판단을 수정할 수 있음
- AI를 포함한 개발 도구의 제안을 스스로 검토하고, 자신이 선택한 기술과 구현 방식의 이유와 한계를 설명할 수 있음
- 코드 리뷰에서 동료의 구현 의도를 충분히 살피고, 자신의 코드에 대한 질문과 피드백을 열린 태도로 논의할 수 있음
- 모르는 점과 실수를 솔직하게 이야기하고, 진행 상황이나 도움이 필요한 문제를 동료에게 적시에 공유할 수 있음
- 맡은 기능의 구현과 연동, 실제 동작 확인까지 마무리하고, 발견된 문제의 해결과 후속 조치에 책임 있게 참여할 수 있음

### 졸업 · 학업 조건

- 학력 무관(직행 표기)
- 졸업 시점, 근무 가능 시기, 병역, 어학 조건은 공고에 없음

### 우대사항

- 서비스를 실제로 출시하고 운영하며, 사용자와 운영자의 반응을 살펴 제품을 꾸준히 다듬어 본 경험
- JavaScript를 활용할 수 있는 환경이라면 익숙하지 않은 영역에도 도전하고, 필요한 것을 익혀 구현해 본 경험
- 해결하려는 문제에 맞는 언어와 도구를 고민하고 선택해 본 경험(업무뿐 아니라 개인 프로젝트에서 다른 언어를 시도한 경험도 포함)
- 사용하는 라이브러리나 프레임워크의 소스 코드와 설계 배경을 살펴 이해를 넓혀 본 경험
- 서비스가 느려지거나 불안정해지는 원인을 찾아 개선하고, 실제로 나아졌는지 확인해 본 경험
- 기존 프로젝트의 기술이나 구조를 바꾸면서 여러 방법을 비교하고, 팀과 제품의 상황에 맞게 선택해 본 경험
- 알게 된 내용과 해결 방법을 코드 리뷰 · 문서 · 도구 등으로 나누어 동료의 작업을 더 수월하게 만들어 본 경험
