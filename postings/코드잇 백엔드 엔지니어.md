## 팀이 하는 일

> 코드잇 프로덕트 팀은 사용자에게 최고의 학습 경험을 제공하고, 회사의 지속적인 성장을 만들어 가는 팀입니다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 코드잇 메인 서비스 개발 및 운영 — 내부 콘텐츠를 유저에게 제공하는 API 개발 · 운영, 가입 · 결제 · 강의 수강 · 커뮤니티 등 프로덕트 전반 개선 | Spring Webflux, Kotlin, MongoDB, GraphQL |
| 실행기 개발 및 운영 — 브라우저에서 코드를 입력하고 결과를 확인하는 실행기 서비스를 빠르고 정확하면서 효율적으로 동작하도록 개선 | Python, JavaScript, Java, MySQL, 브라우저 터미널 |
| 인프라 관리 — 메인 서비스와 실행기가 도는 인프라를 유저 사용 패턴에 맞게 효율적으로 쓰는 방식을 고민하고 개선 | AWS EKS(관리형 Kubernetes) |
| 데이터 분석 — 데이터를 모으고 가공해 내부에 공유하고 프로덕트 개선 방향을 결정 | Amplitude, Google Analytics, 내부 DB |

사용 기술 스택 전체는 Kotlin, GraphQL, Infrastructure(Docker/Kubernetes, CircleCI, Terraform, AWS (EKS, ECS, ECR, S3, SES...))다. 현재 스택에 맞지 않아도 빠르게 배우고 열정 있는 백엔드 엔지니어라면 지원해도 된다고 밝힌다.
