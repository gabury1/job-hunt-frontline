## 팀이 하는 일

> AI Transformation Team은 실제 엔지니어링 현장의 문제를 머신러닝으로 해결하며, 최적의 엔지니어링 솔루션을 끊임없이 탐색합니다.

팀은 Agent System 으로 문제 해결을 자동화하고 솔루션을 지속적으로 탐색 · 개선하는 것과 특정 문제에 최적화된 모델의 설계 · 학습이라는 두 방향으로 일하며, Agent System 을 중심으로 여러 조직과 협업해 AI 모델 최적화 · 하드웨어 설계 등 엔지니어링 문제에 적용하고 Agentic AI 연구 결과를 프로덕션 환경에서 동작하도록 구현한다. 퓨리오사(FuriosaAI)는 2017년에 설립된 추론용 고성능 · 고효율 AI 컴퓨팅 회사로, 주력 칩 RNGD 를 양산하고 있다.
