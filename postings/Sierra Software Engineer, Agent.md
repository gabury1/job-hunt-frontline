- 엔드투엔드 프로덕션 시스템을 구축하고 확장한 경험

- 고객과 직접 일하며 요구를 이해하고 실제 문제를 푸는 데 익숙함
- 영어와 한국어로 기술 · 비기술 청중 모두에게 명확하고 직접적이며 설득력 있게 소통하는 역량

### 졸업 · 학업 조건

- 학력 무관(직행 표기)
- 어학: 영어 · 한국어 소통 역량(필수 역량에 포함). 별도 어학 성적 요구는 공고에 없음

### 우대사항

- 프로덕션에서 AI/LLM 시스템을 구축하거나 배포한 경험
- founder 또는 founding engineer 경험(craft · ownership · speed 의 균형을 앎)
- 오늘날 AI 에이전트를 받치는 도구에 친숙함: eval frameworks, agent tooling, RAG pipelines, prompt engineering
- React, TypeScript, Go 중 하나 이상의 경험
- 고객과 직접 소통하거나 외부 이해관계자와 기술 프로젝트를 이끈 경험
