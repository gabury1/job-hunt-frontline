## 지원 자격

### 필수 경험과 역량

- NLP, LLM 또는 소프트웨어 분야 4년 이상의 연구 · 개발 경력이나 이에 준하는 역량
- LLM, NLP, RAG, 검색, Knowledge Graph 또는 개인화 기술 중 하나 이상을 활용해 제품이나 시스템을 주도적으로 개발한 경험
- 하나 이상의 기술 과제를 설계부터 구현, 평가 및 제품 적용까지 독립적으로 수행한 경험
- Python 을 활용해 제품 또는 서비스 수준의 소프트웨어를 개발할 수 있는 역량
- REST API 또는 비동기 Backend 시스템을 설계하고 개발한 경험
- 요구사항을 구체적인 MVP 와 단계별 개발 범위로 정의하는 역량
- 실험 가설과 평가 기준을 정의하고 정량 · 정성 결과를 분석하는 역량
- 논문, 오픈소스 및 기술 문서를 이해하고 실제 시스템에 적용하는 역량
- Git 기반 협업 개발 및 코드 리뷰 경험

원문이 「이런 분과 함께하고 싶습니다」로 밝힌 인재상은 다음과 같다.

- Agent Memory 를 단순한 대화 저장이나 RAG 기능이 아니라 독립적인 제품 문제로 바라보는 관점
- Memory, Knowledge Base, Conversation History 및 Agent State 의 차이를 구분하고 설명할 수 있음
- 새로운 기술을 빠르게 실험하면서도 실제 사용자와 조직의 문제를 기준으로 우선순위를 정함
- 처음부터 완전한 플랫폼을 만들기보다 가치가 명확한 Use Case 부터 MVP 로 검증함
- 동작하는 프로토타입에서 끝나지 않고 제품 수준의 시스템으로 발전시킬 수 있음
- 모델, 검색, 데이터 및 Backend 구조를 종합적으로 바라보고, Agent 가 Memory 를 활용하는 방식을 이해함
- 연구와 개발 결과를 다른 개발자가 재사용할 수 있는 API, 코드 및 문서로 정리함

### 졸업 · 학업 조건

- 컴퓨터공학, 인공지능, 소프트웨어 또는 관련 분야 학사 이상이거나 이에 준하는 실무 역량을 갖춰야 한다.
- 전공 및 경력: 컴퓨터공학, 인공지능, 소프트웨어 전공이고, 학사 졸업 후 4년 이상 유관 경력 보유자 혹은 인공지능, 자연어처리 관련 분야 석사/박사 학위 보유자여야 한다.
- 병역: 현재 LG AI연구원은 병역지정업체가 아니어서 전문연구요원 채용 및 전직이 불가하다.

### 우대사항

- 인공지능, 자연어처리 관련 분야의 석사 · 박사 학위 보유
- Agent Memory 또는 장기 대화 Context 관리 기능을 구현한 경험
- 사용자 프로필, 개인화, 추천 또는 장기 사용자 모델링 시스템을 개발한 경험
- Keyword Search, Vector Search, Hybrid Search, Re-ranking 또는 Knowledge Graph 등 검색 및 지식 구조화 기술을 활용한 경험
- Memory 의 중복 제거, 충돌 해결, 갱신, 망각 또는 삭제 정책을 설계한 경험
- LLM 또는 검색 시스템의 평가 데이터셋과 자동 평가 체계를 구축한 경험
- FastAPI, gRPC, Docker, Kubernetes 또는 Cloud 환경에서 AI 서비스를 운영한 경험
- 오픈소스 기여, 논문 게재, 특허 출원 또는 기술 문서 작성 경험
