## 팀이 하는 일

> 우리는 로봇 파운데이션 모델이 실제 제품이 되기 위해 필요한, 사람이 이해하고 반복해서 사용할 수 있는 제품 표면을 만들고 있습니다.

리얼월드(RLWRLD)는 Robotics Foundation Model을 개발하는 Physical AI 기업이고, 이 포지션은 teleoperation, data collection, dataset management, fine-tuning, evaluation, deployment, monitoring으로 이어지는 흐름을 하나의 Robotics AI Product Platform으로 만든다. 회사는 최근 다양한 로봇 하드웨어와 환경에 적용 가능한 RLDX-1을 공개했고, 국내외 VC와 대기업에서 약 600억 원 규모의 시드 투자를 받았다. 공고는 단순히 화면을 만드는 프론트엔드 개발자가 아니라, 복잡한 로봇 AI 업무를 검증된 단순한 기술로 상태가 명확하고 운영 가능한 제품 흐름으로 만들 엔지니어를 찾는다고 밝힌다.

## 지원 자격

### 필수 경험과 역량

- Production web application을 설계부터 배포와 운영까지 end-to-end로 개발한 경험
- HTML, CSS, JavaScript, HTTP, browser 동작에 대한 기본기
- 서버가 HTML을 렌더하고 상태를 소유하는 웹 제품을 end-to-end로 만든 경험(예: Rails, Django, Phoenix, Laravel 등 서버 중심 full-stack framework)
- RDBMS 기반 schema, migration, transaction을 설계하고 운영한 경험
- Background job queue로 long-running workflow를 구현하고 운영한 경험
- auth, role-based access control, audit log에 대한 이해
- 복잡한 요구사항을 workflow, state, data model로 정리하는 능력
- 기술 선택을 유지보수, 배포, 디버깅, 팀 크기 관점에서 설명하는 태도

### 졸업 · 학업 조건

- 학력 조건은 공고 본문에 없다(직행 표기는 「학력 무관」이다).
- 병역: 전문연구요원 대상자의 신규 편입 및 전직 지원이 가능하다.
- 졸업 시점 · 입사 가능 시기 · 어학 조건은 공고에 없다.

### 우대사항

ML/Robotics 도메인 제품 경험

- ML, robotics, data 영역에서 workflow product를 만든 경험
- log/timeline, dashboard, replay/video viewer 등 운영형 UI를 만든 경험
- large file, video, model artifact, object storage 기반 제품 기능을 만든 경험

SSR UI 및 Production 운영

- Hotwire, htmx, Phoenix LiveView 등 서버 주도 UI 또는 점진적 향상 방식 경험
- 12-factor app 원칙, secret 관리, migration, backup 등 기본적인 production 운영 경험
- 작은 팀에서 제품의 배포, 운영, 장애 대응까지 직접 해 본 경험

Desktop App 개발 및 운영 경험

- Electron, Tauri 등으로 Desktop application을 개발하고 운영한 경험
- Linux, macOS 환경의 패키징, 코드 서명, 배포 및 자동 업데이트를 운영한 경험

원문의 「이런 분이면 잘 맞습니다」

- 화면보다 사용자가 끝내야 하는 일을 먼저 생각함
- 실패, 대기, stale state, partial success를 제품 언어로 드러냄
- DB가 풀 문제, job queue가 풀 문제, 브라우저 상태로 충분한 문제를 구분함
- 신기술 자체보다 문제 해결에 적절한 기술을 고르고, 단순하고 오래갈 구조를 선호함
