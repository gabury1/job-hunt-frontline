## 팀이 하는 일

> 이 포지션의 본질은 문제 정의의 질에 있습니다.

LinqAlpha 는 기관투자자(헤지펀드 · 자산운용사 · 보험사 등)의 트레이딩과 리서치 프로세스를 돕는 AI 제품을 만드는 핀테크 회사이고, FDE 는 고객마다 다른 리서치 방식에 맞춰 무엇을 에이전트의 일반 행동으로 만들고 무엇을 도메인에 맞춰 엣지에서 깎아낼지 production-grade 로 설계해 last mile 의 품질을 책임진다. 서울과 뉴욕에 코어 팀이 있고 영국 · 싱가포르 · 홍콩에도 멤버가 있으며, 전직 buy-side · sell-side 애널리스트 등 금융 도메인 전문가와 10~20명의 외국인 동료가 함께 일한다.

## 지원 자격

### 필수 경험과 역량

- 고객의 문제를 듣고 기술 이해를 바탕으로 문제를 정의하며, 풀기 위한 데이터 · 컨텍스트의 외연(경계)을 분명히 그리고 소통하는 역량
- 잘 정돈된 reasoning 을 바탕으로 문제 상황에서 핵심을 찌르는 질문을 던지는 역량
- 영어 문서 · 논문 · 금융 데이터를 빠르게 읽고 소화하는 역량(필수). 사내 외국인 동료 · 도메인 전문가, 글로벌 고객사와 영어로 업무 소통이 가능하면 강하게 우대
- Python 또는 TypeScript 로 에이전트를 설계 · 배포 · 모니터링 · 개선까지 end-to-end 로 해 본 경험
- LLM 워크플로우(LangGraph)와 에이전트(Claude Code SDK)를 실제 운영 환경에 scalable 하게 배포해, 프로토타입을 넘어 사용자에게 서빙되는 수준까지 끌고 가 본 경험
- 에이전트가 도는 인프라부터 백엔드 · 프론트까지의 전체 동작을 그리고, 스트리밍(SSE) · stateful 세션 · 비동기 설계로 레이턴시를 다루는 역량
- 모호한 요구와 적은 데이터로도 문제를 정의하고 가설을 세워 빠르게 검증하는 추진력
- Claude Code · Codex 같은 코딩 에이전트를 능숙하게 다루는 AI-native 엔지니어
- 요구 경력 1 ~ 5년
