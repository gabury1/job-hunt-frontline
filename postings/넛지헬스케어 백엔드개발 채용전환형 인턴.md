### 필수 경험과 역량

### 우대사항

기본기를 바탕으로 빠르게 학습하는 분

- Server-side web application 개발 경험
- SQL 데이터베이스의 기본 동작을 이해하고, 쿼리와 인덱스에 관심이 있음
- REST API 또는 GraphQL을 구현해 본 경험
- Functional programming, OOP 등 주요 프로그래밍 패러다임을 학습해 본 경험
- 유닛 테스트와 CI 경험, 또는 앞으로 실무에서 제대로 익히고 싶은 의지

서비스를 끝까지 운영해보고 싶은 분

- 서비스를 만드는 일뿐만 아니라 사용자가 안정적으로 사용할 수 있게 운영하는 일에도 관심이 있음
- 장애나 버그가 발생했을 때 원인을 파악하고 재발을 막는 과정에 흥미가 있음

AI 도구를 적극적으로 활용하는 분

- AI가 매번 다른 답을 내도 일관된 결과를 만들려 고민해 본 경험
- AI 도구를 리팩토링, 테스트 코드 작성, 문서 자동화 등에 활용해 본 경험
- AI가 만든 결과를 그대로 받아들이기보다 본인의 판단으로 검토하고, 재현 가능하며 검증 가능한 결과로 개선할 수 있음

꾸준히 학습하고 기록 또는 공유하며 성장해온 분

- 기술 블로그, 오픈소스 활동, 프로젝트 기록 등 단기간에 만들기 어려운 결과물이 있음
- 좋아하는 오픈소스 개발자가 있거나 오픈소스 프로젝트 참여 경험
- 개발 관련 세미나 참여 혹은 발표 경험

좋은 커뮤니케이션을 중요하게 생각하는 분

- 기획자, 동료 개발자와 필요한 정보를 글로 명확하게 전달할 수 있음
- 본인의 기술적 판단을 개발팀 외 다른 팀에게도 이해하기 쉽게 설명할 수 있음
- 영어 능력이 우수함 (관련 자격증이나 성적이 있으면 함께 기재)

개발자의 디테일을 즐기는 분

- 함수나 변수 이름을 며칠에 걸쳐 여러 번 바꿔 본 뒤 더 나은 이름을 찾아본 경험
- 중복되는 것(코드, 반복되는 일처리, 불필요한 리소스 사용 등)을 줄이는 데 관심이 있음
