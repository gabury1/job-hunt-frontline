## 팀이 하는 일

> MAKE OFFLINE SMART WITH AI

메이아이는 CCTV 영상을 AI로 분석하는 매장 방문객 분석 솔루션 매쉬(mAsh)를 만들고, Product Division의 mAsh Cell은 여러 기업 고객이 이 데이터를 계속 활용할 수 있도록 API와 집계·재처리 시스템을 개발하고 운영한다. 현대자동차·LG전자·스파오 등이 매쉬를 쓰며, 2023년 대비 2026년 예상 매출은 약 5배 규모이고 누적 투자유치액은 130억원 이상이다.

기술 환경은 아래와 같다.

- 언어/프레임워크: Python 3.11, Django, Django REST Framework
- 데이터: PostgreSQL, S3, Parquet, pandas
- 파이프라인/실행 환경: Prefect 기반 분석 실행 환경, Docker
- AI: LLM 연동, LangGraph 기반 대화형 분석
- 인프라/운영: AWS, Datadog
- 버전 관리: Git 기반 소스 코드 및 설정 변경 이력 관리

입사 초기에는 주요 고객 지표와 데이터 흐름, 기존 API·DB 구조를 파악하고 작은 버그 수정과 성능 개선을 맡는다. 이후 집계·재처리·분석 파이프라인 연동과 반복 업무 자동화를 담당한다. 담당 업무는 입사 후 리드와 정하고, 1개월차 원온원과 온보딩 리뷰에서 적응 과정의 어려움과 필요한 지원을 확인한다.
