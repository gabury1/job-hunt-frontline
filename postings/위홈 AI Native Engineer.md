## 지원 자격

### 필수 경험과 역량

- 최적화된 AI Native 바이브코딩 개발 역량
- ChatGPT, Claude, Gemini 및 Cursor, Codex, Claude Code 등의 AI 도구를 능숙하게 활용하고 결과를 검증하는 역량
- LLM API를 활용해 AI Application 또는 AI Agent를 직접 구현한 경험
- RAG, Tool Calling, MCP, Memory와 Workflow 등 Agentic AI의 핵심 구조에 대한 이해
- API, Database, Backend와 외부 서비스를 연결해 End-to-End 기능을 구현하는 역량
- 문제 정의부터 Prototype, 배포, 평가와 개선까지 주도적으로 실행하려는 의지

### 졸업 · 학업 조건

- 학력 무관
- 그 밖의 조건(졸업 시점 · 근무 가능 시기 · 병역 · 어학)은 공고에 없음

### 우대사항

- Computer Science, 소프트웨어, AI 또는 데이터 관련 전공이나 이에 준하는 개발 역량
- LangGraph, OpenAI Agents SDK 등 Agent Framework 활용 경험
- Vector Database, Semantic Search와 Hybrid Search 기반 RAG 시스템 구축 경험
- MCP, Multi-Agent 또는 장시간 실행되는 Agent Workflow 개발 경험
- AI Evaluation, Observability, Guardrail, Human-in-the-Loop와 보안을 실제 서비스에 적용한 경험
- 개인화 · 추천 · CRM · 콘텐츠 자동화 등 AI Native Marketing 기능이나 여행 · 숙박 · 커머스 서비스 개발 경험

모든 기술과 프레임워크를 이미 경험했을 필요는 없다. 특정 도구를 사용한 기간보다 새로운 기술을 빠르게 이해하고, 필요한 도구를 선택해 실제 문제를 해결하는 능력을 중요하게 평가한다. 경력 연수보다 직접 만든 결과물과 문제 해결 능력을 중요하게 본다.
