## 팀이 하는 일

> 광고 노출 이후의 경험을 설계하는 인터랙션 AI 에이전트, 버즈빌

버즈빌은 광고주를 위한 광고 상품 · 운영 시스템과 매체사를 위한 수익화 지면 · SDK를 모두 자체 개발하는 리워드 광고 플랫폼이고, 엔지니어들은 광고 할당 · 리워드 적립 · 정산 · 셀프서브 광고 플랫폼 등 MAU 1,500만 규모의 트래픽을 처리하는 시스템을 만든다. 엔지니어는 한 도메인에 고정되지 않고 비즈니스 임팩트가 큰 프로젝트에 합류한다.

## 담당할 업무

참여하는 프로젝트에 따라 담당 도메인은 달라지지만, 공통으로 아래 업무를 수행한다.

| 업무 | 기술 |
|---|---|
| 광고 플랫폼 백엔드 시스템 설계 · 개발: 광고 상품, 리워드 적립/정산, 셀프서브 플랫폼 등 담당 도메인의 API와 비즈니스 로직 설계 · 구현 | |
| 대규모 트래픽 환경의 서비스 운영 · 개선: MAU 1,500만 규모 트래픽을 안정적으로 처리하기 위한 성능 최적화, 장애 대응, 운영 자동화 | |
| 매체 지면 · 리워드 피처 개발: 오퍼월과 매체 앱 안의 광고 지면, 출석체크 · 미션 · 추첨형 리워드 같은 사용자 참여 피처의 서버 로직과 매체사 적립 포스트백 연동 | |
| 외부 플랫폼 연동: 제휴 광고 네트워크, 커머스 제휴 프로그램, 매체사 적립 포스트백 등 외부 파트너와의 안정적이고 확장 가능한 API 연동 설계 | |
| 기술 부채 해소 및 아키텍처 고도화: 레거시 시스템의 점진적 개선(마이그레이션, 서비스 분리, 쿼리 최적화 등) 참여 | |

업무 범위: 백엔드 개발이 중심이지만, 제품 상황에 따라 프론트엔드(어드민 · 대시보드 등)를 포함한 풀스택 개발로 확장될 수 있다.

개발 환경 (참여하는 프로젝트에 따라 일부 다를 수 있다):

- Backend: Go, Python(Django), MySQL, DynamoDB, Redis, Elasticsearch, Kafka
- Frontend(풀스택 업무 시): TypeScript
- Infra / DevOps: AWS, Kubernetes, Airflow, GitHub Actions, Argo CD, Gitploy
- Monitoring: Datadog, Grafana, Prometheus, Loki, Sentry
- Collaboration / AI Tools: Linear, Jira, Confluence, Slack, GitHub, Claude Code, Cursor, Codex

Go, Python 경험이 없거나 익숙하지 않아도 지원할 수 있다고 공고에 적혀 있다.

## 지원 자격

광고 도메인 경험이 없어도 되고, 문제를 탐구하고 해결하는 태도가 더 중요하다고 공고에 적혀 있다.

### 필수 경험과 역량

- Go, Python 등 하나 이상의 서버 프로그래밍 언어로 동작하는 서비스를 만들어 본 경험
- MySQL 등 관계형 데이터베이스를 사용해 본 경험
- 백엔드에 한정하지 않고, 제품에 필요하면 프론트엔드 등 다른 기술 영역으로 확장하는 데 열려 있음
- 복잡한 문제를 구조적으로 분석하고 기술적으로 풀어낸 경험 (실무 · 연구 · 프로젝트 모두 포함)
- 다양한 직군(PM, 디자이너, 다른 엔지니어 등)과 원활하게 소통하고 협업하는 역량
- AI 도구를 적극적으로 활용하고, 이를 통해 생산성을 높이는 데 관심이 있음
- 경력 무관: 신입부터 지원 가능하다. 학위 과정의 연구 · 프로젝트, 인턴, 개인 프로젝트 등 역량을 보여줄 수 있는 경험이면 충분하다

### 졸업 · 학업 조건

- 전문연구요원으로 복무 가능해야 한다
  - 이공계 석사 이상 학위를 보유(또는 취득 예정)하여 전문연구요원 신규 편입이 가능함
  - 또는 현재 전문연구요원으로 복무 중이며 병무청 전직 요건을 충족함

### 우대사항

- 실서비스 운영: 인턴 · 프로젝트 등에서 실제 사용자가 있는 서비스를 배포 · 운영해 본 경험
- 클라우드 · 컨테이너: AWS 등 클라우드 환경이나 Docker · Kubernetes를 사용해 본 경험
- 데이터 저장소: Redis, DynamoDB 등 NoSQL 저장소를 사용해 보았거나, 데이터 특성에 맞는 저장소 선택을 고민해 본 경험
- 데이터 파이프라인: Kafka, Airflow 등 메시지 큐 · 워크플로 도구를 사용해 본 경험
- 테스트 · 코드 품질: 테스트 코드 작성, 코드 리뷰, 오픈소스 기여 등 코드 품질에 신경 써 본 경험
- 풀스택 개발: 웹 프론트엔드 개발 경험 또는 백엔드와 프론트엔드를 오가며 제품을 만들어 본 경험
- 광고 도메인: 애드테크(AdTech) 생태계에 대한 관심 또는 경험
- 가치관: Fast Fail(빠르게 시도하고 실패에서 배움), 건강한 충돌(건설적인 의견 충돌을 두려워하지 않음), 지속적 성장(새로운 기술과 방법론에 열려 있음), 자기 주도성(모호한 상황에서 주도적으로 방향을 잡음)
