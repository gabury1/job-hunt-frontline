## 지원 자격

### 필수 경험과 역량

- Python 기반 Backend 서버 개발 경험 (참여 프로젝트 포트폴리오 제출 필요)
- API 및 Database 에 대한 이해와 설계 · 구현 · 문서화 역량
- Git, Docker 등 개발 도구에 대한 이해
- Linux 환경에서의 개발 및 작업 경험
- Machine Learning 기법 및 모델의 기본 원리에 대한 이해
- AI 코딩 도구를 효율적이고 책임감 있게 활용하는 역량
- 아래 기술 스택 활용 가능
  - Backend : REST API 설계 · 구현, 비동기 처리, 인증 · 권한 관리 (FastAPI 등)
  - LLM / Agent : LLM API 연동, Tool calling 및 MCP, Agent 프레임워크 활용
  - Data : RDBMS · NoSQL 설계 및 운영, 캐시 · 메시지 큐 (Redis 등)
  - Infra : 컨테이너 (Docker), 오케스트레이션 (Kubernetes), GPU 자원 관리, CI/CD
  - Collaboration : Git 기반 협업, 코드 리뷰 및 기술 문서화

### 졸업 · 학업 조건

- 유관 전공 (컴퓨터공학, 전자 전기공학, 인공지능 등) 학/석사 재학생 및 졸업생
