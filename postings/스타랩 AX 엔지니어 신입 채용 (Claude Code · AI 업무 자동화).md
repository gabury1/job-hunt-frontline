## 지원 자격

### 필수 경험과 역량

- Claude Code 또는 다른 코딩 에이전트로 무언가를 끝까지 만들어 본 경험. 결과물 링크(GitHub, 배포 주소, 시연 영상 중 하나)를 제출할 수 있어야 한다
- Git과 터미널을 기본적으로 다룰 수 있음
- 스킬: Git, GitHub, 프롬프팅, AI Agent
- 핵심역량: 성취지향성, 성장지향성, 창의성, 계획성, 성실성

### 졸업 · 학업 조건

- 학력·전공 무관
- 해외 출장에 결격 사유가 없음

### 우대사항

- Claude Team 플랜 이상에서 관리자를 맡아 본 경험, 또는 AI로 조직을 관리해 본 경험
- 세컨드 브레인 같은 지식 관리 체계를 직접 구축해 본 경험 (온톨로지에 대한 이해 또는 구축 경험)
- MCP 서버, Skills, 훅, 서브에이전트를 직접 만들어 본 경험
- Claude API 또는 Agent SDK로 에이전트를 만들어 본 경험
- 만든 자동화를 다른 사람이 실제로 쓰게 해 본 경험 (동료, 동아리, 고객 등)
- AI 관련 학과 등 공학 계열 전공자
- 반도체·제조·장비 분야에 관심이 있음
- 영어 기술 문서를 읽을 수 있음
- 우대전공: 컴퓨터공학과, 소프트웨어공학과, 인공지능공학과
