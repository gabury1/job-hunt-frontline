## 팀이 하는 일

> Closing the Gap between AI & Reality.

포인랩은 제조 · 산업 현장의 데이터와 시스템, 사람의 업무를 연결해 AI 가 실제 운영 환경에서 작동하도록 만드는 팀이고, 문제 발견부터 설계 · 구현 · 현장 적용 · 운영까지 함께하며 그 경험을 제품으로 발전시킨다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 고객 현장의 업무 · 데이터 · 시스템을 분석하고, AI 로 해결할 핵심 문제와 성공 기준을 정의한다 | |
| AI 기반 솔루션과 프로토타입을 직접 설계 · 개발하고, 실제 데이터와 사용자 피드백으로 검증한다 | |
| 고객의 기존 시스템과 데이터를 연동하고, 솔루션을 실제 업무 환경에 적용한다 | |
| 배포 이후의 기술적 문제를 해결하고, 안정성 · 사용성 · 운영 성과를 개선한다 | |
| 현장에서 검증한 해결책을 재사용 가능한 모듈과 제품 기능으로 발전시킨다 | |

## 지원 자격

### 필수 경험과 역량

- 하나 이상의 프로그래밍 언어로 소프트웨어를 직접 설계하고 구현한 경험
- API, 데이터베이스, 데이터 처리 등 서비스 개발의 기본 구조를 이해하고 활용함
- AI 모델이나 도구를 문제 해결에 활용하고, 결과의 품질과 한계를 검증할 수 있음
- 요구사항이 명확하지 않은 상황에서 필요한 정보를 찾고, 실행 가능한 단위로 문제를 구체화할 수 있음
- 기술적 판단의 근거를 설명하고, 고객 및 동료와 요구사항 · 우선순위를 조율할 수 있음
- 고객 현장의 업무를 직접 이해하고, 개발한 기능의 적용과 개선까지 책임감 있게 참여할 수 있음

### 졸업 · 학업 조건

- 학력: 대졸 이상(졸업예정자 가능)

### 우대사항

- 고객 또는 현장 사용자를 직접 만나 문제를 발견하고 해결한 경험
- LLM · AI Agent · 머신러닝 · 컴퓨터 비전 등을 실제 서비스나 업무 환경에 적용하고 운영한 경험
- AI 시스템의 평가 기준을 설계하고, 정확도 · 응답 속도 · 운영 비용을 개선한 경험
- 기업 내부 시스템, 외부 서비스 또는 현장 데이터를 연동해 본 경험
- 배포 자동화, 로그, 모니터링 등을 활용해 서비스의 안정성을 개선한 경험
- 제조 · 산업 현장의 업무 흐름이나 데이터를 다뤄 본 경험

모든 우대사항을 충족할 필요는 없다. 본인의 강점을 바탕으로 낯선 문제를 어떻게 이해하고 해결해 왔는지 보여 달라고 한다.
