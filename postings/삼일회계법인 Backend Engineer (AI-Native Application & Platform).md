## 팀이 하는 일

> AI가 코드를 빠르게 만들어 내는 시대에 엔지니어의 가치는 무엇을 만들지 정의하고, 어떤 구조로 만들지 설계하며, 그 결과가 실제 운영 환경에서 안전하게 작동하도록 책임지는 데 있다고 생각합니다.

## 지원 자격

### 필수 경험과 역량

- Python, TypeScript, Java 등 하나 이상의 언어를 활용한 백엔드 개발 역량
- REST API 및 서버 애플리케이션 설계 · 개발 경험
- RDBMS 데이터 모델링 및 SQL 활용 역량
- 인증 · 인가, 트랜잭션, 동시성 및 비동기 처리에 대한 이해
- Git, Docker 및 Linux 기반 개발 환경 활용 능력
- AI Coding Agent(Claude Code, Codex, Cursor 등)를 실제 개발에 활용한 경험
- AI가 생성한 코드를 그대로 쓰지 않고 직접 검토 · 테스트 · 개선하는 역량
- 요구사항을 시스템 구조로 구체화하고 독립적으로 개발을 완수하는 역량

### 졸업 · 학업 조건

- 공고 본문(이미지)에는 학력, 졸업 시점, 근무 가능 시기, 병역, 어학 조건이 없다.
- 인크루트 공고 정보에는 학력이 「대졸↑」로 적혀 있다. 직행에는 학력 「무관」으로 적혀 있다.

### 우대사항

- LLM, AI Agent, MCP, RAG 등 AI 애플리케이션 개발 및 운영 경험
- LLM 평가(Eval), 프롬프트 · 모델 버전 관리, 비용 · 성능 최적화 경험
- Temporal, Inngest, Celery 등 워크플로 및 비동기 작업 처리 경험
- MSA, 이벤트 기반 아키텍처 및 분산 시스템 설계 경험
- 클라우드 인프라, Kubernetes, IaC 및 DevOps 경험
- 테스트 자동화, 성능 최적화 및 관측성(Observability) 구축 경험
- OAuth2/OIDC, SSO, RBAC 등 엔터프라이즈 보안 설계 경험
- ERP, 회계, 금융 또는 기업용 B2B SaaS 개발 경험
- 웹툰 · 콘텐츠 플랫폼 등 사용자 대상 서비스 개발 경험
- 프론트엔드 개발 경험 또는 AI 도구를 활용한 풀스택 개발 역량
- 실제 서비스를 설계부터 배포 · 운영까지 주도한 경험

공고가 밝힌 「우리가 기대하는 엔지니어」는 다음과 같다.

- 기능 구현에 그치지 않고 시스템 전체의 구조와 운영까지 고민함
- AI를 적극적으로 활용하면서도 코드 품질과 시스템 신뢰성에 끝까지 책임짐
- 복잡한 업무 요구사항을 명확한 데이터 모델과 비즈니스 로직으로 구현함
- 새로운 기술을 빠르게 학습해 실제 제품에 적용함
- 기획자, 디자이너, AI 엔지니어 및 현업 전문가와 협업해 서비스를 완성함
