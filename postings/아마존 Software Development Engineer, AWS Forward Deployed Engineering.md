## 팀이 하는 일

> FDE Is write production-grade code under the guidance of senior engineers, contributing software components to AI systems that deliver measurable customer business outcomes.

Forward Deployed Engineer I 은 전략 기업 고객사 안에 선임 FDE 와 함께 들어가 AI 기반 프로덕션 시스템을 설계 · 구축 · 배포한다. 초기 경력 단계로서 큰 AI 작업 안의 정의된 과제를 맡아 프로덕션에 나가는 코드를 내고, 정기 점검을 거치며 막히면 위로 올리고, 역량을 보이는 만큼 더 어려운 일을 맡는다.

- 한국어와 영어 모두 비즈니스 수준 구사

### 졸업 · 학업 조건

- Bachelor's degree or equivalent
- Computer Science 또는 관련 분야 학사 이상(또는 동등한 실무 경력)을 February 2025 ~ February 2027 사이에 취득
- 한국에서 합법적으로 근무할 수 있는 자격(비자 스폰서십 불가)

### 우대사항

- 인턴이 아닌 전문 소프트웨어 개발 경력 1년 이상
- Agile · 스타트업 · 빠르게 성장하는 환경에서 1년 이상 일한 경험
- agentic · spec-driven development 경험(AI 에이전트 개발 경험이면 더 좋음)
- AI 도구에 익숙함: eval frameworks, agent tooling, RAG pipelines, prompt engineering
- AI/ML 애플리케이션 구축 또는 배포 경험
- Python, React, TypeScript, Go 중 하나 이상 경험
- coding standards, code reviews, source control, build processes, testing, operations 를 포함한 전체 소프트웨어 개발 생명주기 경험
- 뛰어난 서면 · 구두 소통 역량, customer-facing 환경에 익숙함
