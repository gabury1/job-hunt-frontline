## 지원 자격

### 필수 경험과 역량

- 크롤러를 직접 만들어 본 경험 (개인 프로젝트·부트캠프·인턴 경험 모두 포함)
- HTTP 요청/응답, HTML·DOM 구조, JSON API 응답을 읽고 원하는 데이터를 찾아내는 역량
- 잘 되던 수집이 갑자기 깨졌을 때 원인을 끝까지 파고들어 복구하는 과정에 재미를 느낌
- 시키는 것만 하기보다 "이 데이터 이렇게 쓰면 더 낫지 않나?"를 먼저 말할 수 있음
- 사용자 경험과 고객 가치를 최우선으로 하여 개발을 통해 비즈니스 성장에 기여하고 싶은 열망
- 진짜 '성공'을 만들고자 하는 강한 열망
- Go, Java, Kotlin 등 어떤 언어로든 완성된 서비스를 배포, 개발, 운영한 경험
- 이 업무를 왜 해야 하는지 항상 고민하고, 그 이유를 근거로 팀원들을 설득할 수 있음
- 컴퓨터공학 전공 혹은 이에 준하는 지식 및 활용 역량

### 졸업 · 학업 조건

학력 무관이다. 그 밖의 조건은 공고에 없음.

### 우대사항

- 2년 이상의 관련 경력 혹은 준하는 경험
- 일정 규모 이상(일 수만 건 이상)의 데이터를 지속적으로 수집·적재해 본 경험
- FastAPI, Flask, Django 등으로 간단한 API 서버를 만들어 본 경험
- Playwright, Selenium 등 브라우저 자동화 도구로 동적 페이지를 다뤄 본 경험
- asyncio, 멀티프로세싱 등으로 수집 속도와 효율을 개선해 본 경험
- 장시간 안정적으로 돌아가는 수집 환경을 직접 운영해 본 경험 (요청 스케줄링, 세션·에러 처리, 알림·모니터링 등)
- Docker / Kubernetes 환경에서 배치·워크플로를 운영해 본 경험 (Airflow, ArgoWorkflow 등)
- 커머스·광고 도메인 데이터에 대한 관심
- Go 언어에 대한 관심 또는 익숙함
