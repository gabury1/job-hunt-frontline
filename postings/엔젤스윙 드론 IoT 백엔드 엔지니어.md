## 팀이 하는 일

> 'Safeguard Humanity and Our Planet with Data and Platform'

엔젤스윙은 드론, 리얼리티 캡처, AI/컴퓨터비전 등의 기술로 드론 데이터 플랫폼을 개발하고, 엔젤스윙 3.0 비전 아래 전 세계 여러 나라의 팀원이 하나의 글로벌 팀으로 일한다. 드론 IoT 백엔드 엔지니어는 드론 · IoT 기기와의 실시간 통신을 구현하는 역할로, MQTT 기반 비동기 통신으로 드론 상태를 실시간 확인하고 명령을 내리는 REST API와 백엔드 시스템, 드론 운행 데이터 · 상태 모니터링 백오피스 플랫폼을 맡는다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 드론 및 관련 기기와 통신하는 플랫폼의 백엔드 개발 | |
| 사용자가 드론 상태를 확인하고 명령을 내릴 수 있도록 REST API 중심의 백엔드 설계 및 개발 | REST API |
| MQTT 기반의 실시간 데이터 수집 및 모니터링 시스템 구축 | MQTT |
| 드론의 이용 현황, 상태 등을 모니터링하는 백오피스 플랫폼의 백엔드 개발 | |
| 비동기 처리 기반의 IoT 서비스 아키텍처 설계 및 최적화 | |

사용 기술은 다음과 같다.

- 언어: Python
- 프레임워크: FastAPI
- 데이터베이스: MongoDB, Motor
- 메시징 프로토콜: MQTT, aiomqtt
- 기타 도구: Injector
