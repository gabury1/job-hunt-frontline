## 지원 자격

### 필수 경험과 역량

- React 또는 Next.js로 서비스를 만들어 본 경험
- JavaScript 또는 TypeScript 사용 경험, HTML/CSS 기본기
- API 서버나 데이터베이스를 직접 설계하거나 연동해 본 경험
- Git 기반 협업 경험
- AI가 만든 코드의 오류와 품질을 직접 검토하고, 실제 서비스에 넣어도 되는지 판단하는 역량
- 유관 부서와 소통하며 일정을 관리하는 역량
- 새 기술을 배우는 일을 즐거워함

공고는 함께하고 싶은 사람을 다음과 같이 밝힌다. 기능 하나를 사용자에게 닿을 때까지 끝까지 책임지는 사람, 디자인 디테일을 코드로 정확하게 구현하는 사람, AI를 활용해 빠르게 만들되 결과물을 직접 검증하는 사람, 디자이너 · PM과 편하게 소통하며 문제를 해결하는 사람, 에이전시의 노하우를 제품으로 전환하는 일에 흥미를 느끼는 사람이다.
