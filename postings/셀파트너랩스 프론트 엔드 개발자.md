## 팀이 하는 일

> “AI로 미래에 잘 팔릴 상품을 찾는다!”

셀파트너랩스는 온라인 판매자가 상품을 효율적으로 관리하고 매출을 극대화하도록 AI 기반 솔루션을 제공하는 「AI 이커머스 솔루션 기업」이다. 팀은 개발자, 마케터, UI/UX 디자이너로 구성되어 있고, 관리하는 프로덕트가 확장되어 사용자 중심의 프론트 엔드를 전담할 인원을 찾고 있다.

## 지원 자격

### 필수 경험과 역량

- React를 활용한 프론트엔드 개발 경험
- JavaScript 또는 TypeScript로 웹 기능을 구현하는 능력
- REST API를 연동해 데이터를 조회·등록·수정하는 화면을 개발하는 능력
- HTML, CSS를 활용해 다양한 화면 크기에 대응하는 UI를 구현하는 능력
- Git을 활용한 협업 경험과 작업 내용을 동료에게 명확히 공유하는 능력
- 개발한 기능의 오류를 직접 확인하고 수정하는 능력

공고에 없음
