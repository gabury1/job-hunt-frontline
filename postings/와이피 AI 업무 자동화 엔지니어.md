## 지원 자격

### 필수 경험과 역량

- Claude Code 등 AI 개발 도구를 실무에서 활용한 경험
- Python 또는 JavaScript · TypeScript로 개발할 수 있음
- API 연동과 데이터 처리 경험
- AI 에이전트 · 업무 자동화 시스템을 구축한 경험
- 기획부터 개발, 배포, 유지보수까지 혼자 수행할 수 있음
- 실제로 사용할 수 있는 웹 또는 데스크톱 프로그램을 만든 경험
- 실제로 작동하는 결과물(깃허브, 배포 링크, 데모 등)을 보여 줄 수 있음

### 졸업 · 학업 조건

- 학력은 무관하다. 원문은 「학력 · 나이 · 경력 연차보다 실력을 우선합니다」라고 밝힌다.
- 졸업 시점, 근무 가능 시기, 병역, 어학 조건은 공고에 없다.

### 우대사항

- 혼자 AI 프로그램을 개발한 경험, 개인 서비스를 출시한 경험
- 직접 만든 프로그램으로 수익을 낸 경험
- MCP, n8n, Make, FFmpeg 등 영상 처리 기술을 활용한 경험
- 반복 업무를 분석해 자동화로 시간을 크게 줄인 경험
- 영상 편집 · 유튜브 콘텐츠 제작이나 마케팅 업무에 대한 이해
- 새로운 AI 모델과 서비스를 직접 써 보고 업무에 바로 적용함

## 제출 서류와 지원 방법

- 지원하는 곳: 원티드 공고 페이지에서 지원한다.
- 처음에 내는 서류: 공고에 없다. 다만 자격요건에 깃허브, 배포 링크, 데모처럼 실제로 작동하는 결과물을 보여 줄 수 있어야 한다는 조건이 있다.
- 전형 중에 내는 증빙 서류: 공고에 없음

## 유의사항

- 원문은 주요업무가 확정된 내용이 아니고 미팅을 통해 이야기를 나눈다고 밝힌다.
- 혜택으로 업무용 AI 프로그램 및 개발 환경 지원, 사내 프로그램을 외부 상품과 구독형 서비스로 키우는 일에 참여하는 기회를 적었다.
- 별도의 유의사항과 문의처는 공고에 없다.
