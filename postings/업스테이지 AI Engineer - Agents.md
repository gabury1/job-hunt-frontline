## 팀이 하는 일

> Agent Engineering팀은 모델의 능력을 실제 세계의 동작으로 전환하는 일을 책임집니다.

프롬프트 구성, 모델 출력 해석, 실제 환경에서의 안전한 액션 실행, 서비스 운영 경험을 더 나은 모델과 agent 동작으로 환원하는 과정까지, 모델을 둘러싼 시스템 전체를 다루는 팀이다. 연구 조직과 가장 가까이에서 agent 실행 구조부터 추론, 격리된 실행 환경, 작업 조율, 품질 평가, 서비스 안정성까지 맡는다. AI Engineer는 agent를 인상적인 데모가 아니라 믿고 쓸 수 있는 도구로 만드는 역할이다.
