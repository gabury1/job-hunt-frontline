## 팀이 하는 일

> 지식을 담고, 그 지식으로 답하는 AI 에이전트를 함께 만듭니다

뉴로코어는 AI 기술로 공급망 관리 솔루션을 제공하는 기업이고(홈페이지 https://neurocore.ai/), 이 팀은 수요 · 재고 · 자재 · 생산계획 · 설비 · 공정까지 계산 가능한 모델로 옮긴 공급망 위에, 현업의 자연어 질문을 쪼개 SQL 로 데이터를 조회하고 근거와 함께 답하는 AI 에이전트를 올린다. 팀이 가장 시간을 많이 쓰는 문제는 쿼리는 성공하고 숫자도 나오지만 정답이 아닌 경우이고, 모델을 키우는 대신 절차 지식 카드 · Semantic Layer · 검증 · 평가 · 경보로 도메인 지식을 구조화해 넣는다.

## 지원 자격

### 필수 경험과 역량

- 경력은 연차 무관이고 신입 지원이 가능하다. 몇 년 했는지보다 무엇을 스스로 정해서 만들어 봤는지, 「그때 왜 그렇게 했는지」를 설명할 수 있는지를 본다.
- Python 으로 돌아가는 것을 직접 만들어 본 경험(회사 업무 · 개인 프로젝트 · 연구 무관, 남이 짠 코드를 고친 것이 아니라 스스로 구조를 잡아 본 것)
- SQL 로 데이터를 조회하고 검증할 수 있는 수준
- 아래 둘 중 하나 이상
  - LLM API 또는 오픈소스 모델로 서비스 · 도구를 만들어 본 경험
  - 데이터 모델링 또는 스키마 설계 경험
- 알고리즘, 자료구조, 데이터베이스 등 기본적인 전산 지식에 대한 이해
- 유관부서 · 도메인 전문가와 소통하며 업무를 진행하고 결과를 효과적으로 전달한 경험

### 졸업 · 학업 조건

- 학력 · 전공 무관, IT 기본 역량 보유자는 누구나 지원 가능하다(산업공학 · 소프트웨어공학 · 컴퓨터공학 · 인공지능 관련 전공은 우대).
- 병역특례(전문연구요원)가 가능하다.

### 우대사항

- RAG 운영 경험: Chunking · Reranking · Query Rewriting
- LangGraph · LangChain 등 Agent Framework 사용 경험
- Text-to-SQL(NL2SQL) 또는 생성된 SQL 을 검증해 본 경험
- LLM Evaluation 설계 경험(평가 데이터셋, 회귀 격자, 지표)
- Knowledge Graph · Ontology · Semantic Layer(dbt, Cube 등) 경험
- Structured Output · Tool Calling · LLM Context 설계 경험
- 도메인 전문가가 직접 쓰는 비개발자용 내부 도구를 만들어 본 경험
- 도메인 전문가 인터뷰로 지식을 구조화해 본 경험

## 유의사항

- 허위사실이 발견될 경우 채용이 취소될 수 있다.
- 해당 채용은 병역특례(전문연구요원)가 가능하다.
- 일하는 데 필요한 도구는 회사가 산다. AI 코딩 도구는 상위 요금제 기준으로 구독료를 지원하고, 다이어그램 · 설계 도구인 Lucidchart 라이선스도 제공한다. 업무에 필요한 도구는 편하게 제안할 수 있다.
- 팀은 LLM 을 업무에 적극적으로 활용한다. 코딩뿐 아니라 설계 검토 · 문서화 · 데이터 정리 등 반복 업무에 AI 를 쓰고, 사람은 무엇이 맞는지 판단하고 더 나은 방법을 찾는 일에 집중한다.
- 문의처: 공고에 없음
