## 팀이 하는 일

> 당근에 쌓이는 모든 콘텐츠와 유저를 깊이 이해해서 데이터로 만들고, 그 데이터를 당근의 모든 서비스가 믿고 쓸 수 있도록 하는 것

중고거래 · 동네생활 · 모임 · 동네업체 · 광고 · 커머스 · 숏폼 등 여러 도메인의 콘텐츠를 일관된 분류 체계(Taxonomy)로 정의하고, 매일 수십만 건씩 생성되는 콘텐츠에서 AI로 카테고리와 속성을 자동 추출하며, MAU 2100만 유저의 앱 내 행동을 바탕으로 의도·상태·선호를 태그로 추론한다. 이 데이터는 피드 · 검색 · 추천 · 광고 등 여러 서비스가 공통으로 쓰는 기반이 되고, 특히 피드 추천과 검색 품질을 개선하는 핵심 데이터로 쓰인다.

## 지원 자격

### 필수 경험과 역량

- 실제 서비스 규모로 백엔드 시스템이나 데이터 파이프라인을 설계·운영한 경험
- LLM API를 프로덕션 시스템에 통합하고 운영한 경험
- 대용량 배치·스트림 처리 시스템이나 데이터 웨어하우스로 대규모 데이터를 다룬 경험
- 분류 체계나 데이터 모델을 설계하고, 여러 팀이 공통으로 사용하는 데이터 자산을 만든 경험

### 졸업 · 학업 조건

- 학력 무관
- 산업기능요원 채용 가능(현역 전직, 보충역 신규 편입, 보충역 전직). 전문연구요원 편입 및 전직은 불가하다

### 우대사항

- LLM 프롬프트와 출력 품질을 평가하는 체계(골든셋, LLM-as-a-judge, 품질 지표)를 직접 설계·운영한 경험
- LLM 호출의 비용·처리량을 최적화한 경험
- 유저 행동 데이터를 바탕으로 유저 모델링이나 세그먼트·태그 추론을 한 경험
- 콘텐츠를 분류하는 시스템이나 지식 체계(taxonomy, ontology)를 구축한 경험
- LLM 출력을 학습 데이터로 활용해 ML 모델을 학습하거나 증류한 경험
