## 팀이 하는 일

팀 소개는 공고에 없다. 스포츠투아이는 국내 최대 규모의 스포츠 데이터처리 전문기업이다. 프로구단, 방송사, 포털사 등 주요 고객사와 함께 다양한 스포츠 리그 데이터를 바탕으로 콘텐츠와 S/W 등을 개발하며, K-Sports AI Tech 시장을 선도하고 있다.

## 지원 자격

### 필수 경험과 역량

- C#/.NET 또는 Java 기반 웹 애플리케이션 개발 기본기(Java 전공자나 경험자는 .NET 전향 의지 필수)
- React.js 기반 프런트엔드 개발 프로젝트 수행 경험(HTML, CSS, ES6+ JavaScript 이해)
- RDBMS(MSSQL 등) 기초 지식 및 SQL 쿼리 작성 능력
- RESTful API 설계 및 클라이언트-서버 간 연동에 대한 이해
- 원활한 협업 태도, 코드 리뷰와 피드백에 열려 있는 자세

공고는 필요역량으로 다음 다섯 가지를 든다.

- 새로운 기술 스택(.NET 8, React)을 빠르게 배우려는 의지와 흡수력
- 방대한 레거시 코드를 파헤쳐 문제 원인을 규명하는 끈기 있는 디버깅 역량
- 논리적인 사고에 기반한 문제 정의 및 해결 능력
- 명료한 개발 문서화와 적극적인 커뮤니케이션 태도
- 트래픽 급증이나 경기 일정 등 실시간 변동성에 대응하는 유연한 판단과 복구력

### 졸업 · 학업 조건

- 해외여행에 결격사유가 없음(남성의 경우 병역 필 또는 면제자)
- 학력, 졸업 시점, 근무 시작 시기는 공고에 없음

- 어학자격 소지, 외국어 독해와 커뮤니케이션에 능통함
