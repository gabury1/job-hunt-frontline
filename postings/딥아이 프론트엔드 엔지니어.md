## 팀이 하는 일

> 인공지능 기반 비파괴검사로 더욱 안전한 플랜트 환경을 만들어 갑니다.

딥아이는 AI 기술로 비파괴검사의 정확도와 효율성을 극대화하는 인공지능 기반 비파괴검사 자동평가 솔루션을 개발한다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 검사 분석 웹 서비스 및 데스크톱 애플리케이션 프론트엔드 개발 | Electron |
| UI 컴포넌트 설계·구현 및 공용 디자인 시스템 구축·운영 | React, TypeScript |

| 백엔드·AI 팀과 협업한 API 연동 및 실시간 데이터 처리 | Socket.IO, SignalR |
| 에러·사용성 모니터링 및 서비스 품질 개선 | Sentry, PostHog |

공고에 적힌 기술 스택은 Git, React, JavaScript, Python, TypeScript, AWS, DevOps, NoSQL, Docker, RDBMS, Restful API 이다.
