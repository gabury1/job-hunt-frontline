## 팀이 하는 일

> 확장 가능하고 유연한 피드 서비스를 통해 모든 로컬 서비스가 당근 하나로 연결되는 세상을 꿈꾸고 있어요.

피드 인프라팀은 당근 유저가 가장 먼저 만나는 화면인 홈 피드를 책임지고, 유저가 좋아하는 콘텐츠를 모아 안정적으로 서빙하면서 어떤 모양으로 보여 줘야 더 좋을지 고민한다. 홈 피드의 인프라와 추천 · 랭킹을 맡은 피드실은 추천 · 랭킹 파이프라인과 실험 환경을 정비해 새 캐러셀을 붙이고 개인화하고 실험하는 비용을 크게 낮춰 왔다.

## 담당할 업무

| 업무 | 기술 |
|---|---|
| 팀 엔지니어들과 함께 기능을 개발하고 코드 리뷰를 주고받으며 운영 대응까지 맡는다 | |
| 홈 피드 신규 캐러셀을 처음부터 끝까지 맡는다: 데이터로 기회를 찾고 가설을 세운다 | |
| 어떤 콘텐츠를 후보로 모아 어떤 기준으로 골라 보여 줄지 설계한다 | |
| 캐러셀을 홈 피드에 붙이는 서버를 개발하고 출시한다 | |
| A/B 실험을 하고 결과를 분석한다 | A/B 실험 |
| 어떤 콘텐츠를 캐러셀로 만들지, 홈 피드의 어디에 얼마나 자주 보여 줄지 목표에 맞춰 제안하고 검증한다 | |

맡게 될 지면은 홈 › 피드 글 사이 캐러셀이다. 목표는 사용자가 새 캐러셀에서 필요한 것을 발견하고 홈 피드를 다시 여는 모습을 확인하는 것이고, 캐러셀 클릭만 보지 않고 홈 피드 전체의 체류와 재방문을 해치지 않으면서 새 가치를 더했다는 걸 A/B 실험으로 확인한다. 피드실 엔지니어가 설계와 코드 리뷰를 함께 하고, 콘텐츠를 가진 서비스 팀 · 디자이너 · 클라이언트 개발자와 협업한다.

팀에서 쓰는 기술은 Go, gRPC, gRPC-Gateway, MySQL, MongoDB, Redis, Kafka, Kubernetes, Istio 다. 위 기술을 써 보지 않았더라도 괜찮다고 밝혔다.
