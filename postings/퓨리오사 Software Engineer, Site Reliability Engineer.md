## 팀이 하는 일

> 프로덕션 시스템을 개선해 장애가 격리되고, 우아하게 성능이 저하되고, 빨리 감지되고, 안전하게 복구되게 한다(Reliability Architecture).

SRE 는 baremetal Kubernetes 클러스터, cloud control plane, 네트워킹, 관측성 시스템, 배포 파이프라인, Furiosa NPU 위에서 도는 API 서비스 전반을 맡아 Reliability Architecture · Observability & SLOs · Production Engineering 세 축으로 신뢰성 · 확장성 · 보안 · 운영성을 높인다. 퓨리오사AI는 2017년 설립된 AI 추론용 고성능 · 고효율 컴퓨팅 회사로, 주력 칩 RNGD 를 TSMC 에서 양산 중이다.
