## 지원 자격

### 필수 경험과 역량

신입 지원 시 요구사항이다.

- 개발 포트폴리오 보유(신입은 포트폴리오가 있어야만 지원 가능)
- Java 및 Node.js 웹 개발에 능숙함
- Spring Boot 프레임워크에 익숙함
- MySQL/NOSQL 등 SQL 문법에 대한 높은 이해도
- Git을 통한 Version Control 경험

경력 지원 시 요구사항이다.

- 총 근무개월수의 합(실제 근무경력) 3년 이상
- Language: JAVA
- Framework: Spring boot
- DBMS: MariaDB, MySQL, NoSQL
- ORM: JPA, MyBatis
- AWS Cloud / Linux
- RESTful API
- Source Control: Git
- MSA(Microservices Architecture)

잡코리아 모집요강의 스킬 칸은 API, JAVA, MariaDB, MyBatis, MySQL, Spring Boot, Restful API 이고, 핵심역량은 성실성, 성취지향성, 적응성, 창의성, 협동심, 메타인지, 성장지향성이다.

- 신입: 컴퓨터공학/전산학과 계열 대졸 이상 또는 직무 관련 아카데미 최소 6개월 이상 수료

- 병역 · 어학 조건은 공고에 없다

신입 지원 시 우대사항이다.

- 팀원 의존적인 성향보다 본인 주도적인 문제해결이 가능함
- 생성형 AI사 API(ChatGPT/HyperclovaX)를 활용한 경험
- webpack을 사용한 경험
- devOps 또는 새로운 기술 적용에 관심이 많음
- Linux 개발 환경에 익숙함
- SI 개발자 성향이 아닌 애자일 방식의 린스타트업 개발자 성향

경력 지원 시 우대사항이다.

- 온디바이스 LLM(Meta Llama3) 기반 RAG 개발에 관심이 많음
- AWS Cloud / Microsoft Azure 환경 기반 아키텍처 구성 및 개발 경험

잡코리아 기본우대 조건이다.

- 유관업무 경험자(인턴 · 알바)
- 포토샵 능숙자
