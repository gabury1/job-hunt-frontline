## 지원 자격

### 필수 경험과 역량

- Java 또는 Kotlin, Spring Boot 로 웹 서버를 개발할 수 있거나 개발해 본 경험 (학교 · 개인 · 팀 프로젝트 포함)
- 웹 서비스가 동작하는 구조(HTTP, 웹 서버 · WAS, DB, 캐시 등)에 대한 기본적인 이해
- RDB 와 SQL 기본기, REST API 를 설계 · 구현해 본 경험
- 새로운 기술과 도메인을 빠르게 학습하고, 모르는 것을 질문하며 함께 해결해 나가는 역량

### 졸업 · 학업 조건

- 기졸업자 및 27년 2월 졸업예정자만 지원 가능
- 남자는 군필자 또는 면제자만 지원 가능
- 해외여행에 결격 사유가 없어야 함

### 우대사항

- 직접 만든 서비스를 배포 · 운영하며 장애나 성능 문제를 해결해 본 경험
- AI 코딩 도구를 활용해 개발 생산성을 높여 본 경험
- 국가유공자 및 장애인 등 취업보호 대상자는 관계법령에 따라 우대
