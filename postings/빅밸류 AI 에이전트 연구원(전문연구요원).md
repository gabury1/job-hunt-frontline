## 지원 자격

### 필수 경험과 역량

- 서비스 내 · 외부의 정형/비정형 데이터를 분석하고 전처리 · 정제 · 검증할 수 있는 역량
- 복잡한 도메인 데이터를 이해하고, 이를 Agent가 활용할 수 있는 논리적인 데이터 구조로 설계할 수 있는 역량
- Python 기반의 LLM/Agent 프레임워크를 활용해 실제 애플리케이션을 구축해 본 경험
- Agent 결과의 정확성, 근거 적절성, 실패 원인을 분석하고 개선 방향을 도출할 수 있는 역량

### 졸업 · 학업 조건

- 컴퓨터공학, 데이터 사이언스, 통계학 또는 관련 분야의 학위 보유(석사 이상 선호)
- 학력: 무관(직행 표기)
- 병역: 전문연구요원(병역특례) 채용이다. 편입 요건은 공고에 없음

### 우대사항

- 문제를 직접 정의하고, 해결 방향을 찾아본 증명/검증한 경험
- 데이터 수집, 전처리, 구조화, 벡터화, Agent 적용까지의 전체 흐름을 경험해 본 경험
- Agent 결과의 원인을 분석하고, 데이터 · 구조 · 프롬프트 · 평가 기준을 재설계/개선해 본 경험
- NLP(자연어 처리) 관련 주요 학회(ACL, EMNLP, NeurIPS 등) 논문 게재 경험
- 최신 AI 트렌드를 빠르게 습득하고 실제 프로토타입으로 구현하는 것을 즐김
