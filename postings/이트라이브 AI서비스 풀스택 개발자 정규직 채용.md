## 지원 자격

### 필수 경험과 역량

- 경력 1년 이상
- LLM 서비스 동작 방식(프롬프트 설계, RAG, 에이전트 도구 호출 등)을 실무 수준으로 이해함
- 에이전틱 코딩 도구(Claude Code, Cursor 등)로 아이디어를 빠르게 동작하는 프로토타입으로 만드는 역량
- TypeScript / JavaScript, Python 등으로 프론트엔드(Next.js 등)와 백엔드(Node.js, Python 등) API를 개발하고 운영해 본 풀스택 경험
- 기술과 비즈니스 양쪽 언어를 이해하고, 제안서나 기획 산출물(PRD)을 구조적으로 작성하여 원활하게 커뮤니케이션하는 역량
- 잡코리아 모집요강의 스킬 항목: JAVA, Node.js, Python, ReactJS, RestAPI, TypeScript, 풀스택, RAG, LLM, langgraph

### 졸업 · 학업 조건

- 학력: 초대졸 이상
- 졸업 시점 · 병역 · 어학 조건은 공고에 없음

### 우대사항

- LangGraph로 멀티 노드·오케스트레이터 기반 서비스를 구축한 경험
- vLLM, SGLang 등으로 LLM 모델을 서빙한 경험 및 Chat 기반 RAG 시스템을 구축한 경험
- LLM API를 활용해 실제 서비스를 배포하고 운영한 경험
- 3D·모션 등 인터랙티브 웹 개발 경험, 또는 모노레포 환경에서 빌드를 최적화하거나 테스트 자동화(E2E)를 구축한 경험
- 공공·대형 RFP 제안이나 B2B 세일즈 문서를 작성한 경험
- 원문에 실린 「우리가 맺고 싶은 동료상」
  - 실행 중심의 벤처 마인드: 한 달 동안 기획서만 다듬기보다 이번 주에 당장 동작하는 것을 만들어 눈으로 확인하고 개선하는 쪽을 택함
  - 자기 주도적 문제 해결: 정답이 없는 환경에서도 문제를 스스로 구조화하고, 새로운 기술(새로운 AI 모델, 도구 등)을 능동적으로 탐색해 빠르게 적용함
  - 유연한 확장성: 특정 개발 직무만 고집하지 않고, 팀의 성공을 위해 기획, 영업 지원, 운영 등 다양한 역할을 기꺼이 넘나듦
