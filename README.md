# 취업최전선

개발자 신입 채용 공고 정제본

지금 접수 중인 국내 개발 신입 · 주니어 공고를 매일 아침 모아, **AI 에 그대로 먹이기 좋게** 정리한 마크다운입니다.

> **AI 에게는 [AGENTS.md](AGENTS.md) 하나만 주면 됩니다.** ChatGPT · Claude 같은 웹 채팅이라면 아래 주소를 붙이고
> 「여기서 내 조건에 맞는 공고 골라 줘」라고 하세요. Codex · Cursor · Claude Code 는 레포를 열면 알아서 읽습니다.
>
> `https://raw.githubusercontent.com/gabury1/job-hunt-frontline/main/AGENTS.md`

원문은 각 채용 사이트에 흩어져 있고 이미지로만 올라온 공고도 많아서, 공고마다 일정 · 전형 · 담당 업무 · 지원 자격 · 제출 서류를 같은 틀로 다시 적었습니다.

- 갱신: 매일 아침(한국 시간 9~10시쯤). 마감된 공고는 빠집니다. 지난 공고는 git 기록에 남습니다.
- 마지막 갱신: 2026-11-24 · 접수 중 공고 443건 · 회사 326곳

## 범위와 한계

**이 레포는 만든 사람 한 명의 지원 기준으로 거른 목록입니다.** 기준이 다르면 빠진 공고가 많습니다.

| 기준 | 넣는다 | 뺀다 |
|---|---|---|
| 직무 | 서버 · 백엔드, 소프트웨어 엔지니어, DevOps · SRE, 생성형 AI 서비스 개발(LLM API · 에이전트 · RAG 를 붙이는 개발), 인프라(큰 회사 공고만) | 프론트엔드 · 웹 풀스택, 데이터 엔지니어, 임베디드, 모델을 직접 학습시키는 연구, 비개발 직무 |
| 요구 경력 | 신입 ~ 「2년 이상」, 「3년 이하」처럼 상한만 있는 공고 | 「3년 이상」 |
| 회사 | 대형 IT · 핀테크 · 대기업 IT 계열사 · 후기 · 성장 스타트업 · 외국계 · 전통 금융 IT · 자체 제품이 있는 중견 · 중소 SW 회사 | SI · SM · 파견(고객사 시스템을 만들어 주는 곳), 초기 스타트업, 공공기관, 비IT 회사의 사내 IT 조직 |
| 출처 | 직행 · 점핏 · 자소설닷컴 | 원티드 · 사람인 · 잡코리아 직접 수집(직행이 긁어 온 것은 들어 있음) |

- 카테고리 · 직무 분류와 남길지 뺄지는 AI(Claude)가 공고 글과 회사 조사를 보고 판정했습니다. 잘못 분류되거나 빠진 공고가 있을 수 있습니다.
- 「큰 회사」 칸은 대형 IT · 핀테크 · 대기업 IT 계열사 · 은행 · 카드 · 증권 같은 금융사 공고를 따로 모은 것입니다. 좋은 회사라는 평가가 아닙니다.
- 회사 노트는 공개된 자료(홈페이지 · 기술 블로그 · 뉴스 · DART · 투자 정보)로만 썼고, 조사 시점이 노트에 적혀 있습니다.

## 파일

| 경로 | 무엇 |
|---|---|
| `AGENTS.md` | AI 에게 주는 안내: 파일 구조 · 고르는 순서 · 지킬 것 |
| `postings.jsonl` | 공고 한 줄에 하나. 회사 · 제목 · 카테고리 · 직무 · 요구 경력 · 마감 · 올라온 날 · 원문 링크 · 노트 경로 · 큰 회사인지(`big_company`) · 오늘 새 공고인지(`new_today`). **AI 에는 이 파일부터 주세요** |
| `오늘의 공고.md` | 그날 아침 새로 올라온 공고만 |
| `공고 현황.md` | 접수 중 전체. 큰 회사 · 나머지(마감이 가까운 순서) · 상시 채용 세 칸 |
| `postings/` | 공고마다 노트 한 장: 한눈에 · 일정과 전형 · 팀이 하는 일 · 담당할 업무 · 지원 자격 · 제출 서류와 지원 방법 · 유의사항 |
| `companies/` | 회사마다 조사 노트: 사업 · 성장(투자 · 재무 · 인원) · 최근 이슈 · 리스크 · 개발 문화 · 업무 방식 · 처우 · 출처 |

## AI 에게 이렇게 쓰면 됩니다

- 「postings.jsonl 에서 마감이 2주 안 남은 백엔드 신입 공고를 골라 줘. 내 이력서는 이거야」
- 「postings/<공고>.md 와 companies/<회사>.md 를 읽고 이 공고 자기소개서 방향을 잡아 줘」

## 주의

- 공고 노트와 회사 노트는 AI(Claude)가 원문을 읽고 정리했습니다. 원문의 사실은 바꾸지 않도록 했지만 틀릴 수 있으니, **지원 전에는 꼭 원문 링크를 확인하세요.**
- 공고의 저작권은 각 회사에 있습니다. 이 레포는 찾기 쉽게 다시 정리한 사본입니다.
- 회사 리뷰 사이트(블라인드 · 잡플래닛)의 리뷰 내용은 싣지 않습니다.
- 이 공고들을 모으고 정리하는 도구가 어떻게 돌아가는지는 [도구 설명](TOOL.md)에 있습니다.
