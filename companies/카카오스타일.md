## 업무 방식 · R&R

### 팀 구성

- 서버 팀이 제품과 도메인 기준으로 나뉜다. 직행 공고에 지그재그 서비스, 전시 시스템, 물류 시스템, 글로벌뷰티 백엔드가 따로 올라와 있다.
- 지원 공고의 지그재그 서비스 파트는 홈, PLP, 북마크, 찜, 랭킹 화면 API와 Server-Driven UI 플랫폼을 맡는다.
- Product Owner 공고(지그재그서비스, 배송&물류)가 있어 기획자 · PO가 따로 있다.
- 데이터 조직, 기획, 마케팅과 협업한다 (리멤버 공고).

### 신입이 맡을 역할

- 공고가 적은 업무는 화면 API 설계와 운영, 마이크로서비스 간 인터페이스 설계, A/B 테스트 기능 개발, 기존 코드 개선, AI 에이전트 활용 자동화다.
- 요구 경력이 0~6년이어서 신입도 지원할 수 있으나, 자격요건은 MSA 장애 전파 설계 경험과 지표 기반 개선 경험을 요구한다. 신입에게 실제로 어느 수준을 기대하는지는 과제 전형과 면접에서 확인해야 한다.

### 일하는 방식

- 핵심 가치에 「스스로 일합니다」, 「투명하고 솔직하게 소통합니다」, 「빠르게 시도합니다」가 있어 자율형을 지향한다 (홈페이지).
- 리뷰에는 리더가 오래 머문 사람 중심이라는 불만이 있어, 실제 의사결정이 얼마나 열려 있는지는 면접에서 물어볼 만하다.
- 온콜과 운영 부담은 못 찾음.
- 협업 도구는 못 찾음. 블로그 태그에 Slack과 Jenkins가 보일 뿐이다.
