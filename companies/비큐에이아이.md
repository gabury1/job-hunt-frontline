## 업무 방식 · R&R

### 팀 구성

- 블로그 소개문 기준으로 제품 중심 조직으로 개편하는 중이다. 구체적인 팀 구성은 못 찾음.
- 기획자 · PM 유무는 못 찾음. 공고에는 개발자가 UI 요건을 정의하는 업무가 들어 있다.

### 신입이 맡을 역할(공고 기준)

- 모집 형태는 「(인재POOL) 개발직군」이며 채용 절차는 인재풀 등록 후 공고가 열리면 연락하는 방식이다. 지금 바로 뽑는 공고는 아니다.
- 행정문서와 신문 지면 텍스트 전처리를 맡는다.
- 개체명 인식(NER) 모델 파인튜닝과 지식 그래프 구축을 맡는다.
- 벡터 DB 구축과 지식그래프 기반 RAG 시스템 개발을 맡는다.
- FastAPI 또는 Spring Boot 기반 API를 개발하고 운영한다.
- 오픈소스 LLM 폐쇄망 구축과 맞춤형 DB 스키마 설계를 맡는다.
- 데이터 분석 결과로 웹 UI 요건을 정의한다.
- 담당 범위가 데이터 처리부터 모델, API, 화면 요건까지 넓다.
- 자격요건이 LLM/RAG 관련 NLP 정보 검색 시스템 개발 경험과 Elasticsearch 기반 벡터 DB 구축 · 운영 경험이다. 신입에게는 높은 기준이다.

### 일하는 방식

- 공고에 정시 퇴근, 자유로운 연차, 회식 강요 없음이 적혀 있다.
- 공고에 나이와 직급에 관계없이 「프로님」 호칭과 존댓말을 쓴다고 적혀 있다.
- 재택 · 원격 여부, 협업 도구, 의사결정 방식, 온콜 부담은 못 찾음.
