### 기술 스택

- 블로그 · API 문서에 서버 언어 · 프레임워크 · 클라우드 · DB 는 적혀 있지 않다.
- Data API 는 JWT Bearer 인증, `api.bigvalue.co.kr` 아래 REST GET, JSON 응답이다(docs.bigvalue.ai).
- 오류 응답이 `detail` 필드를 쓴다. FastAPI 기본 오류 모양과 같지만 확인된 것은 아니다(추정).
- 지금 공고는 「Python 기반 LLM·Agent 프레임워크」 경험을 요구한다.
- 마감된 공고 중 「웹 풀 스택 개발자 React / Java (신입 / 전문 연구 요원)」이 있었다(직행 회사 페이지). 웹 쪽에 Java 를 쓰는 것으로 보인다.
