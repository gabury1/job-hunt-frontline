### 기술 스택 (채용 사이트 블로그 · 공고)

- 백엔드: Kotlin/Spring 기반 MSA 로 바꾸는 중이고 레거시 모듈을 걷어 내고 있다 (백엔드 크루 인터뷰).
- 백엔드 팀장 공고: Spring Boot(Kotlin/Java) 대규모 웹 애플리케이션 경험을 요구한다.
- 배치: Spring Boot Batch 서버로 데이터를 가공 · 적재한다 (CTO 글).
- DB: AWS Aurora MySQL · RDS MySQL/MSSQL (CTO 글, Cloud DBA 공고).
- 데이터: GCP BigQuery 와 AWS DMS 로 Replica DB 를 실시간 동기화한다 (CTO 글).
- 메시징: Kafka 를 「적극 장려」한다. 랭킹보드 · 로그 적재 · 블록체인 데이터 수집에 쓴다 (CTO 글).
- 모니터링: Grafana (CTO 글).
