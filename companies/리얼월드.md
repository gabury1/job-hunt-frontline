### 기술 스택

- 모델 학습: AWS EC2 p5e · p5en (H200 GPU)을 씁니다.
- 시뮬레이션 평가: AWS EC2 g6e (L40S GPU)를 씁니다.
- 학습 오케스트레이션: AWS ParallelCluster와 Slurm을 씁니다.
- 저장소: Amazon S3와 FSx for Lustre를 동기화해서 씁니다. 데이터는 수백 TB 규모입니다.
- 시뮬레이션: NVIDIA Isaac Lab-Arena, Newton, GR00T를 씁니다.
- 제품 웹 (Product Engineer 공고 기준): Rails · Django · Phoenix · Laravel 같은 서버 렌더 풀스택 프레임워크, RDBMS, 백그라운드 잡 큐를 요구합니다.
- 우대 기술: Hotwire · htmx · LiveView, Electron · Tauri 데스크톱 앱, Linux · macOS 패키징과 코드 서명입니다.
- Staff Engineer 공고는 Python · Java 프로덕션 애플리케이션을 언급합니다.

- 의사결정은 자율형을 지향한다고 밝혔습니다 (채용 페이지의 「From top-down to a bottom-up organization」 문구). 다만 이것은 회사가 스스로 밝힌 내용입니다.
- 「Global is the assumption from day one」이라고 적혀 있습니다. 이력서는 한글이나 영문으로 냅니다.
- 전형은 서류 → 1차 인터뷰 → 2차 인터뷰 → 최종 합격 순서입니다. 필요하면 커피챗이나 코딩테스트가 들어갑니다.
