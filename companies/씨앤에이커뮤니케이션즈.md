### 기술 스택 (공고와 홈페이지 실측)

- 웹: PHP (모든 페이지가 `.php`입니다)
- 웹 서버: Apache (응답 헤더)
- 문자 인코딩: EUC-KR (API 문서에도 「EUC-KR에서 지원되는 문자만 사용 가능」이라고 적혀 있습니다)
- 프론트엔드: jQuery 1.7 · 2.2.4, jQuery UI, jQuery EasyUI
- DB: MySQL · Microsoft SQL Server (2026 공고)
- 그 밖에: Delphi · Windows Server · Linux · 스위치 · 방화벽 (2018 공고의 「선임자에게 배울 수 있는 기술」 목록)
- PC에 설치하는 「기능 확장팩」 프로그램이 있습니다. 브라우저의 로컬 네트워크 접근 권한을 요구하므로 로컬 에이전트 방식으로 보입니다(홈페이지 안내문 기준).
- API: `https://balsong.com/Linkage/API/` 하나의 주소에 POST · JSON으로 요청하는 방식입니다. 팩스 · 문자 · 알림톡 · 브랜드메시지 · 메일 · 수신거부 · 예약발송 기능을 제공합니다.
- 홈페이지와 API 문서에는 오래된 라이브러리와 EUC-KR 인코딩이 남아 있습니다. 레거시 코드를 유지보수하는 비중이 클 것으로 보이지만, 이 판단은 추정입니다.
