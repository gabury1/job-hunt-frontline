## 성장

### 투자 · 지배 구조
- 투자 유치 대상 아님. SAP SE의 한국 자회사다.
- 연구소 매출은 그룹 대상 용역매출 하나뿐이고, 영업이익률이 해마다 5~6% 로 거의 일정하다. 원가에 일정 이윤을 붙여 본사에 청구하는 구조로 보인다 (추정 · 근거는 아래 표의 일정한 이익률).

## 리스크

- 적자 · 자본잠식: 없음. 2023~2025 3년 연속 영업이익 흑자, 자본총계 314.0억 원 (DART).
- 그룹 구조조정: 2024년 1월 발표한 전사 구조조정이 약 8,000명 → CFO 추산 9,000~10,000명 규모로 커졌고 2025년 1분기에 끝났다 (SAP 실적 페이지 · CIO).
- 상시 감원: 2025년 보도에 따르면 CFO가 매년 전 세계 인력의 1~2% 를 줄이는 방식을 밝혔다 (heise).
- 채용 동결 성격: 2026-07 부터 신규 채용이 핵심 AI 직무 중심으로 좁혀졌다 (Bloomberg). 이 공고는 AI 직무가 아니어서 실제 채용 진행 여부를 지원 전에 확인할 필요가 있다.
- 비용 센터 구조: 연구소는 그룹이 원가를 대 주는 구조로 보인다 (추정). 인원 · 예산은 본사 결정에 달려 있다.
- 리뷰에서 반복되는 불만: 성장 · 커리어. 커리어 향상 3.6 으로 항목 중 가장 낮고, 제목에 「성장은 모르겠음」 · 「큰물은 아님」 · 「고인물」 · 「공무원 같은 회사」가 되풀이된다.
- 소송 · 규제: 연구소 관련 건은 못 찾음.

## 업무 방식 · R&R

### 팀 구성
- 제품 · 엔진 모듈 단위로 나뉜 것으로 보인다. 서울 공고 이름에 드러난 팀:
  - HANA Cloud SQL Optimizer · SQL 처리 (이 공고)
  - HANA 데이터베이스 커널
  - HANA Cloud 멀티모델 엔진
  - HANA Cloud 데이터 페더레이션
  - HANA Cloud 성능 엔지니어링
  - HANA Cloud 컨트롤 플레인
  - HANA 툴링
  - HANA DevSupport (개발 지원)
  - SAP Analytics Cloud planning 개발
- Development Manager · Product Manager 직함이 있다 (Labs 페이지 직원 소개). PM 이 존재한다.

### 신입이 맡을 일 (이 공고)
- HANA Cloud 데이터베이스의 데이터 관리 · 처리 기능 개발.
- SQL optimizer · SQL execution engine · SQL script · SQL expression · plan cache 기능 개발.
- 자기가 만든 기능의 end-to-end · unit 테스트 작성.
- 대규모 데이터 처리 산업 기술 조사.
- 북미 · 유럽 · 아시아 동료와 공동 개발.
- 경력 무관 · 정규직 · 학사 이상 (컴퓨터공학 등) · 공고 원문 게시 2026-10-17 (직행 표기, 원티드 출처).

### 신입 경로
- 서울 「Vocational Training Program Intern」(2026/2027 졸업자 대상, Database Core SQL Plan Mgmt · Kernel · DevSupport 등) 공고가 있다. 과거 공고에는 프로그램 절반(9개월) 이수와 졸업 뒤 정규직 지원이 가능하다고 적혀 있다.
- 「Developer Associate」 같은 졸업자 대상 정규직 공고도 있었다.
