## 리스크

- 영업적자가 2023 · 2024 · 2025 세 해 연속이다 (DART).
- 2026 3분기 누적으로도 연결 영업손실 20억이 남아 있다 (뉴시스).
- 자본잠식은 아니다. 2025 말 자본총계 179.4억이 자본금 51.0억보다 크다 (DART).
- 부채비율은 2026 2분기 기준 155.6% 다 (네이버 증권).
- 2024 년 매출이 전년보다 31% 줄고 영업손실이 149억까지 커진 해가 있었다. 프로젝트 매출이 몰리고 빠지는 데 따라 실적이 크게 흔들린다.
- 주가가 스테이블코인 · 가상자산 테마에 따라 움직인다 (2026-01 급등, 2026-02 급락). 52주 범위가 1,992~7,670원이다.
- 매출 대부분이 고객사 구축(SWSI)과 유지관리(AMS)다 (딜사이트). 프로젝트 수주가 끊기면 인력 가동률이 바로 떨어지는 구조다.
- 구조조정 · 소송 · 규제 제재 소식은 못 찾음.
- 리뷰에서 반복되는 불만은 셋이다.
  - 프로젝트(부서) · 사람에 따라 업무 강도와 경험이 크게 다르다 (「부바부」 「프바프」 「프로젝트가 무엇이냐가 중요한 회사」).
  - 급여 · 경영진 점수가 낮다 (항목별 평점 2.9 · 2.8).
  - 오래 다니기 어렵고 유능한 사람이 나간다는 제목이 여럿이다.

### 기술 스택

- 공고 기준: Java · Spring Boot · Spring Batch · Oracle · MySQL · MyBatis · React · Node.js · Unix/Linux Shell.
- DevOps 공고 우대: Jenkins · Git · AWS · Kubernetes(EKS).
- 자사 프레임워크 BXM 위에서 개발한다 (신한은행 기사).
- 제품 BX-CoCore 는 마이크로서비스 · 컨테이너 기반이고 IBM LinuxONE · x86 에서 검증했다고 홈페이지에 적었다.

### 일하는 방식에서 드러나는 것

- AI 개발 도구를 직접 만들어 판다. BXCA(코드 어시스턴트) · AICA(요건 → 코드 생성, RAG · CI/CD · MCP 연동, 요건을 테스트 시나리오로 바꾸는 TDD 체계) · BXCode Agent(자율형 코드 에이전트)가 있다.
