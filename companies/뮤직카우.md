## 리스크

### 재무

- 3년 연속 영업손실이다 (별도 160.5억 → 127.6억 → 146.6억 원).
- 당기순손실은 3년째 늘었다 (255.6억 → 266.2억 → 346.5억 원).
- 누적 결손금은 2025년 말 1,356.1억 원이다 (DART).
- 자본잠식은 아니다 (자본총계 1,115.7억 원 · 자본금 13.3억 원).
- 차입금이 늘었다 (2024년 말 358.8억 → 2025년 말 444.1억 원, 단기 · 유동성장기 · 장기 합산, DART).
- 2025년 말 현금및현금성자산은 37.0억 원이다 (별도, DART).
- 100% 자회사 뮤직카우포트폴리오인베스트먼트에서 319.3억 원을 빌렸다 (바이라인네트워크 2026-07-22).
- 저작권 자산 순장부가 1,193.4억 원 중 900.4억 원(75.5%)에 담보가 설정돼 있다 (같은 기사).
- 뮤직카우에셋의 저작권평가충당금이 2024년 33.0억 원에서 2025년 125.6억 원으로 늘었다 (DART).

### 규제 · 사업

- 사업이 아직 혁신금융서비스 특례에 기대고 있고, 정식 인가는 받지 못했다 (SBS Biz 2026-09-23).
- 첫 예비인가 신청(2025-09)부터 1년 넘게 인가가 끝나지 않았다.
- 장외거래소(넥스체인지)도 본인가 심사 중이다 (2026-09 기준).
- 거래 유동성이 낮다는 지적이 있다 (2025-02 기준 1,122곡 중 194곡만 거래, 한국경제).
- 구조조정 · 소송 보도는 찾지 못했다.

### 기술 스택 (공고 기준)

- 백엔드: Java · Spring Boot · JPA (인턴 · 시니어 공고 자격 요건)
- 우대: QueryDSL · Redis
- 레거시: PHP 기반 시스템이 있고 Java/Spring으로 단계적 전환을 계획 중 (개발팀장 공고)
- 클라우드 · 인프라: 공고에 적힌 것 없음 (인프라팀장 별도 채용 중, 직행)
- 원티드 공고의 기술 스택 칸은 비어 있다.

### 일하는 방식

- 코드 리뷰: 시니어가 「코드 리뷰로 팀의 개발 기준을 세운다」고 공고에 적혀 있다.
- 코드 리뷰 · 배포 기준 · 장애 대응 체계는 개발팀장이 새로 세울 일로 적혀 있다 (지금은 정착돼 있지 않을 가능성, 추정).
