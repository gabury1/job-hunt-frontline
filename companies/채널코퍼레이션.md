## 업무 방식 · R&R

### 팀 구성

- Product 조직은 Feature 팀과 Core 팀 두 축이다.
- Feature 팀: AI 상담 · 실시간 음성 · 업무 자동화 · CRM·마케팅. 리더 · 엔지니어 · PM · 디자이너가 함께 있는 목적 조직이고 매출 · 활성 사용자 KPI 를 진다.
- Core 팀: BE · Client · AppStore · SWE 팀 등. 내부 플랫폼 · 공통 기반 · 기술 부채를 맡는다.
- 백엔드는 Core 아래 여러 「셀」로 나뉜다 (예: API 코어 셀).
- 그 밖에 FDE 팀 · On-Premises 팀 · DevOps 팀 · AI 팀이 있다.
- 첫 팀은 인터뷰를 바탕으로 회사가 제안하고 함께 정한다 (Software Engineer 공고).

### 신입이 맡게 될 역할

- Software Engineer(Backend): 채팅 · 상담 · 고객 · 결제 도메인 서버 설계, Go 신규 서비스, Java·Dropwizard API 개선.
- 「고객과 제품 문제를 함께 정의하고 설계 · 출시 · 운영 · 개선까지 결과를 책임진다」 (공고 원문).
- 신입은 서비스 영향이 적은 과제부터 시작해, 결과를 보이면 더 주도적인 과제를 받는다 (백엔드 헤드 인터뷰).
- 몇 주 ~ 1.5~2개월 동안 함께 일하며 판단 기준을 맞춘 뒤 위임 범위를 넓힌다.
- 전사 온보딩 버디와 팀 리더가 결과물을 함께 리뷰한다.
- 커머스팀 백엔드는 카페24 · Shopify 등 쇼핑몰 솔루션 10곳 이상 연동을 맡는다 (2026-11-19 블로그).
