## 리스크

- 적자 · 자본잠식: 2022~2025년 4년 모두 영업흑자다. 자본잠식은 아니다.
- 부채비율이 500% 안팎이고 자기자본비율이 16%다. NICE 안정성 지표는 「최하위(13)」다.
- 차입금의존도가 72%이고 이자보상배수가 2.62배다 (2024년 7.06배에서 낮아짐).
- 2025년 투자활동 현금 유출이 42.8억 원으로 커졌다. 비유동자산이 19.6억 → 60.5억 원으로 늘었다. 무엇에 썼는지는 못 찾음.
- 영업활동 현금흐름은 2025년에야 플러스로 돌아섰다.
- 거래액의 41%가 K-POP 굿즈라 한류 · 아이돌 일정에 매출이 기댄다 (벤처스퀘어 카테고리 비중 기준 해석).
- 구조조정 · 소송 · 규제: 못 찾음.
- DA팀 AI 플랫폼 엔지니어 공고가 2026-08-27 에 올라 10-11 에 마감된 뒤 10-24 에 다시 올랐다 (직행). 프로덕트 디자이너 공고도 여러 번 다시 올랐다.

### 기술 스택 (확인한 것만)

- 웹 프런트: Next.js (응답 헤더 x-powered-by) · React · TypeScript (프론트개발팀 공고).
- 인프라: AWS CloudFront 뒤에서 서빙된다 (응답 헤더).
- 백엔드: GitHub `b2b-sample` 레포가 Kotlin · Spring Boot 3.2 · JPA · Java 17 이다. 그룹 이름이 `io.delivered-korea.b2b.sample` 이고 설명은 「b2b 개발 틀을 잡기 위한」이다.
- AI: Python · FastAPI · MCP · RAG (DA팀 공고).
- 고객 지원: 채널톡 (홈페이지 도움말 센터 링크).

### 일하는 방식에서 드러나는 것

- 프론트개발팀 공고가 Claude Code · Cursor · Copilot 실무 사용을 자격 요건으로 둔다.
- 같은 공고가 「AI가 작성한 코드를 읽고 판단 · 수정할 수 있는 기본기」를 요구한다.
- 같은 공고가 SDD(명세 · 테스트 우선 개발)와 Sub Agent · MCP 워크플로우 경험을 우대한다.
- DA팀 공고도 「스펙 주도 개발 기반의 프로토타입 제작」을 담당 업무로 적는다.

### 이번 공고에서 맡을 일 (DA팀 AI 플랫폼 엔지니어)

- MCP 에이전트 워크플로우를 만들어 반복 업무를 자동화한다.
- RAG 기반 검색 · 번역 · 추천 기능을 설계하고 성능을 개선한다.
- FastAPI · MCP 로 AI 기능 모듈을 만들어 B2C · B2B 플랫폼에 붙인다.
- 스펙 주도 개발로 프로토타입을 만들고 서비스까지 완성한다.
- 자격: LLM 활용 프로젝트 경험(파인튜닝 · 프롬프트 · 에이전트 설계 · RAG · 바이브 코딩 등).
- 자격: Python 기반 API · MCP 설계 · 개발 · 연동 경험.
- 우대: 이커머스 · 물류 도메인 경험.
- 우대: 데이터 수집 파이프라인 구축 · 학습용 데이터 정제 경험.
- 경력 조건: 1년 이상 (잡코리아 원문). 신입 지원 가능 여부는 공고에 없다.
