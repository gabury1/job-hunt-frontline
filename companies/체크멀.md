## 업무 방식 · R&R

**팀 구성**
- 공고에 따르면 개발은 제품별로 네 영역으로 나뉜다.
  - Windows용 AppCheck: 커널 드라이버, 사용자 영역 앱, 화면 앱, 서버 연동
  - Linux용 AppCheck: 커널 드라이버, 사용자 영역 앱, 서버 연동
  - CMS: Golang 백엔드와 React 프런트엔드, 사내 여러 시스템과의 연동
  - 백오피스: 3rd-party 협력사용 백오피스와 정보 보호용 백오피스
- 각 영역의 인원은 찾지 못했다.
- 2025년에 제품기획 직군과 QA 직군을 채용했다 (테크42). 따라서 기획 · QA 담당이 따로 있을 가능성이 있지만 현재 인원은 확인하지 못했다.

**신입이 맡게 될 일 (오늘 공고 기준)**
- 리눅스 보안 개발자(주니어)
  - AppCheck Linux 제품을 개발하고 운영한다.
  - 리눅스 드라이버(커널)를 개발하고 변경 요청에 대응한다.
  - 서버와 통신하는 리눅스 네트워크 앱을 C와 Golang으로 개발하고 운영한다.
- 윈도우 보안 개발자(주니어)
  - Windows 드라이버를 개발하고 시스템 내부 동작을 분석한다.
  - 악성코드 탐지와 시스템 보호 기술을 구현한다.
  - Windows 환경의 위협을 분석하고 대응한다.
- 두 공고 모두 경력 0~3년, 상시 채용, 경기 근무 조건이다.
- 두 공고 모두 「개발하고 운영한다」고 적어 두었으므로 출시 뒤 고객 이슈 대응까지 맡을 것으로 보인다. 온콜 여부는 찾지 못했다.
- 서버 백엔드에 가장 가까운 일은 리눅스 공고의 「서버 연동 네트워크 앱(Golang)」과 CMS 백엔드(Golang)이다. 그러나 CMS 백엔드 신입 공고는 지금 없다.

**일하는 방식**
- 출근 근무가 기본으로 보인다 (공고 근무지 경기 용인).
- 재택근무: 사람인의 기업 직접 입력 복지 목록에는 있지만 공고에는 적혀 있지 않아 확인이 필요하다.
- 근무 시간: 하루 7시간, 주 35시간 탄력근무이며 8~10시 사이에 출근한다 (공고, 테크42).
- 협업 도구: Jira (공고)
