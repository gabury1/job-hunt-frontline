## 업무 방식 · R&R

**팀 구성**

- 채용 페이지는 직무를 Dev · Product · Biz · Back Office로 나눈다.
- Product 조직에는 프로덕트 매니저와 프로덕트 디자이너, QA 매니저가 있다. 따라서 기획자 · PM이 있다.
- Biz 조직은 나라별(일본 · 대만 · 태국) 크리에이터 파트너십 매니저와 캐스팅 · 운영 · 콘텐츠 직무로 나뉘어 있어 비중이 크다.
- 제품별 조직이나 목적 조직이 있는지는 못 찾음이다.

**신입이 맡게 될 역할**

- 지금 신입을 뽑는 개발 자리는 웹 프론트엔드뿐이다. 맡는 일은 구독 · 크리에이터 페이지 · 팬 피드 화면 개발과 Nuxt 4 전환, 모바일 웹 개선이다.
- 서버 공고는 그동안 경력 3~5년으로 나왔고, 지금은 마감되어 있다.
- 서버 공고에 적힌 업무는 라이키 API 설계 · 개발이다.
- 같은 공고에는 인하우스 운영 툴과 관리 페이지 개발도 들어 있다.
- 같은 공고에는 빌드 · 배포 환경 개선과 성능 · 비용 최적화도 들어 있다.
- 같은 공고에는 통계용 데이터 적재 · 가공과 콘텐츠 모니터링 보안 강화도 들어 있다.

**일하는 방식**

- 휴가: 무제한 자율 휴가 제도가 있고, 리더 승인과 구성원 사전 공유를 거친다 (공고).
- 협업 도구: 서버 공고는 Git · Slack · Google Workspace 경험을 우대한다. 사내에서 이 도구를 쓰는 것으로 보이지만 추정이다.
- 요구사항 처리: 개발자가 모호한 요구사항을 기획자와 확인하고 스펙에 반영하는 구조다 (프론트 공고).
- 온콜 · 운영 부담: 못 찾음
