  - 「방향은 모호함」 · 「우선순위 타령」이라는 최신 리뷰가 있다.

- 공고: LLM 으로 상품 속성(제품 속성 · 체감 속성)을 추출 · 체계화하는 카탈로그 시스템 구축.
- 공고: LLM 기반 쇼핑 AI Agent 기능 설계 · 개발.
- 인턴 인터뷰에서 본 실제 과제: 커머스 가격 · 혜택 데이터 파이프라인 · 카테고리 분류기 고도화 · 패션 카탈로그 시스템 · 프론트 모노레포 전환.
- 첫날부터 실제 프로덕트 코드를 따라가며 배포될 파이프라인을 개발했다는 인턴 증언이 있다.
- 조건: 3개월 인턴 · 월 400만 원 · 기간 협의 가능 · 정규직 전환 기회 있음.
- 전형: 서류 → 직무 과제 → 전화 인터뷰 → 대면 인터뷰 → 최종 합격.
