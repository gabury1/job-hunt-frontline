- 팬덤엔진을 특허 · 기술 리포트로 증명하는 일에 참여한다.
- 「모델 연구가 아니라 실제 라이브에 들어가는 제품을 만드는 자리」라고 공고에 적혀 있다.
- 백엔드 · 데이터 · 실시간 · 에이전트를 한 사람이 넓게 맡는 범위로 읽힌다(공고의 담당 업무로 판단).

**일하는 방식**

| 항목 | 내용 |
|---|---|
| 출근 | 서울 잠실 스파크플러스 출근 · 원격 근무 언급 없음 |
| 시간 | 시차출퇴근 · 코어타임 11~17시 |
| 도구 | AI 도구 · 구독 · 장비를 회사가 지원 · 협업 도구 이름은 못 찾음 |
| 의사결정 | 수평적 토론, 빠른 결정과 실행 우선(홈페이지 Careers) |
| 기획자 · PM | CPO가 있고, AI Native PM(신입~5년차)을 채용 중이다 |
| 온콜 · 운영 | 매일 정해진 시간에 라이브를 하고 무중단 라이브 기록도 있다 · 온콜 규정은 못 찾음 |
| 수습 | 3개월 |

**채용 절차(홈페이지 AI 빌더 공고)**
- 서류 → 1차 인터뷰(30분) → 3일 유급 실전 과제 → 최종 인터뷰 → 합격 순서이다.
- 서류에 직접 만든 것의 링크(repo · 데모 · 서비스)가 꼭 있어야 한다.
- 1차 인터뷰에서 평소 AI로 개발하는 화면을 15분쯤 함께 본다.
- 실전 과제는 개인정보를 지운 라이브 채팅 기록으로 캐릭터가 방송을 이끄는 작은 엔진을 만드는 일이다.
- 지원서에 좋아하는 캐릭터 · 작품 · 크리에이터와 그 이유를 한 문단 쓰라고 요청한다.

- 연봉은 3일 유급 과제를 마친 뒤 최종 인터뷰에서 직접 확인해야 한다.
