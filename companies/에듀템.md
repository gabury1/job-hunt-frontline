- 구조조정 · 소송 · 규제 소식은 못 찾음.

### 기술 스택 (신입~3년 공고 기준)

- 언어: Python
- LLM 프레임워크: LangChain · LangGraph
- LLM API: OpenAI · Claude · Gemini
- Vector DB: Qdrant · pgvector (경력 공고는 Pinecone · Chroma 도)
- API 서버: FastAPI
- 인프라: Docker · AWS · Azure
- 개발 도구: Claude Code · Codex · Gemini CLI · Grok 같은 AI 코딩 에이전트
- 에이전트 설정: Skills · MCP 서버 연동과 커스텀 설정 · Markdown 문서 작성
- 옛 공고(리멤버)는 Python · TensorFlow 로 음성 · 언어 모델을 직접 학습하는 일이었다.

- AI 코딩 에이전트 활용과 「에이전트 작업 설계 및 결과물 검증」을 필수 기술로 적은 점이 특이하다. 개발 방식 자체를 에이전트 중심으로 바꾸려는 것으로 보인다.
