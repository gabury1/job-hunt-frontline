### 기술 스택 (확인된 것만)

- Python 프로덕션 코드 (공고 필요 역량).
- LLM · RAG · AI Agent 파이프라인 (공고 담당 업무).
- 온프레미스 OSS 모델 + 외부 고성능 LLM 을 나눠 쓰는 「멀티 엔진」 구조 (홈페이지 핵심 경쟁력).
- GPU 일체형 어플라이언스로 폐쇄망 설치 (머니투데이).
- CI/CD · 형상 관리 · ML 모델 버전 관리 · A/B 테스트를 묶은 AXL-Ops (제품 페이지).
- AXL-Shift 는 COBOL→Java, DB2→Oracle 같은 레거시 변환을 다룬다 (제품 페이지).
- 백엔드 언어 · 프레임워크 · 클라우드: 못 찾음.
