### 기술 스택 (공고에서 확인)

- 언어와 프레임워크는 Java와 Spring Boot입니다.
- 주차관제 공고의 우대사항에 「ORM 도메인 모델링 (JPA, Exposed)」이 적혀 있습니다. Exposed는 Kotlin ORM이므로 Kotlin을 일부 쓸 가능성이 있지만 **추정**입니다.
- ORM은 Spring Data JPA입니다.
- DB는 MySQL과 AWS Aurora입니다.
- 클라우드는 AWS 멀티 계정입니다 (EC2, Elastic Beanstalk, EKS, RDS/Aurora, VPC).
- 인프라 도구는 Kubernetes(EKS)와 Terraform입니다.
- CI/CD 도구는 Jenkins와 ArgoCD입니다.
- 모니터링 도구는 Datadog과 CloudWatch입니다.
- 인증 방식으로 OAuth2와 JWT가 나옵니다 (파트리더 공고).
- 데모데이에 올라온 공고에는 GitHub · React · JavaScript · Python · Jenkins 태그가 붙어 있습니다. 그런데 백엔드 공고와 프론트엔드 공고에 같은 태그 묶음이 붙어 있어서 Python의 실제 쓰임새는 확인되지 않습니다.

- 백엔드 파트리더가 주니어 · 미들급 개발자의 코드 리뷰와 기술 멘토링을 맡습니다 (리멤버 파트리더 공고).
