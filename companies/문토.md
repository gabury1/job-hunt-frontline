**일하는 방식** (기술 블로그와 공고)
- 코드 리뷰를 합니다. 캐릭터챗 팀도 문토 개발팀과 "코드 리뷰와 기술 논의를 함께"합니다.
- GitHub Actions의 self-hosted runner에서 Claude CLI와 Gemini CLI가 PR을 자동으로 리뷰합니다(블로그 1편).
- self-hosted runner를 쓴 이유는 Claude CLI의 웹 로그인 방식이 브라우저가 없는 가상 서버에서 동작하지 않았기 때문입니다(블로그 1편).
- 자동 리뷰는 develop, test, main 브랜치로 PR이 생성되거나 업데이트될 때만 실행됩니다(블로그 1편).
- 자동 리뷰를 도입한 계기는 서버 로직을 제대로 검토하지 못하고 배포했다가 장애가 난 경험이었습니다(블로그 1편).
- 블로그는 자동 리뷰 덕분에 평균 30분이 걸리던 초기 리뷰가 3분으로 줄었다고 적었습니다.
- AI가 Figma 디자인을 분석해서 Patrol(앱)과 Playwright(웹) E2E 테스트 코드를 만들고, 결과를 QA팀의 Google Sheets에 기록합니다(블로그 2편).
- 블로그 2편은 AI가 만든 코드를 "항상 사람이 한 번 더 검토해야 했다"고 적었습니다.
- Swagger 명세를 먼저 쓰고 AI로 NestJS와 Flutter 코드를 만든 다음 테스트로 검증하는 API-First 방식을 소개했습니다(블로그 3편).
