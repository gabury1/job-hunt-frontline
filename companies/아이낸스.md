### 기술 스택
- 공고에 적힌 언어: C · C++ · C# · Visual C·C++ · Python
- 공고에 적힌 DB: MySQL · OracleDB
- 공고에 적힌 OS: Unix · Linux · Windows
- 공고에 적힌 자격증: 정보처리기사
- XtM 플랫폼(서버용 미들웨어)은 CEP(Complex Event Processing) 엔진으로 실시간 시세를 처리합니다
- XtM 플랫폼은 여러 프로토콜(Stream packet · XML · JSON)을 지원합니다
- XtM 플랫폼은 저장소로 Shared memory, SAM 데이터 표준 API, 관계형 DB, 메모리 DB 를 지원합니다
- K-PATS(서버자동주문)는 가원장을 공유 메모리(SHM)에 두어 잔고 변화를 빠르게 감지하고 원장 부하를 줄입니다
- K-PATS 는 엔진을 다시 컴파일하지 않고도 새 감시 전략을 추가할 수 있다고 소개되어 있습니다
- 기사는 핵심 구조를 「멀티 스케일아웃」 병렬처리 엔진과, 시세 연계와 원장 연계를 서로 독립시킨 설계로 소개합니다

### 일하는 방식
