- 등록 주소가 여수 · 안산 · 용산으로 자료마다 다르다.
- 사업이 오픈마켓 데이터 수집과 마켓 연동에 기대고 있다. 그래서 각 마켓의 정책 변화에 영향을 받을 수 있다(구체적인 분쟁이나 규제 사례는 못 찾음).

## 업무 방식 · R&R

- 팀 구성: 개발자 · 마케터 · UI/UX 디자이너로 이루어진 직무별 소규모 팀이다(공고).
- 프론트엔드 공고를 낸 이유: 프로덕트가 늘어나면서 프론트엔드를 전담할 사람이 필요해졌다고 밝힌다.
- 지금 열린 역할: Next.js 대시보드 화면 개발 · 백엔드 API 연동 · 상품 탐색 · 추천 · 등록 기능의 사용성 개선이다.
- 책임 범위: 공고에는 「기능의 설계부터 서비스 적용까지 참여」라고 적혀 있다.
- 백엔드 신입이 맡을 역할: 현재 백엔드 공고가 없어 못 찾음.
- 2025-07 모집 글에 적힌 백엔드 업무는 REST API 설계 · DB 설계 · 최적화 · 크롤러 설계였다(이 모집은 마감됨).
- 고용 형태: 인턴 3개월 뒤 정규직으로 전환하는 형태이다.
- 근무 방식: 출근을 기본으로 하고 주 1회 재택이 가능하다.
- 기획 담당: 공고에는 「기획 · 디자인 · 백엔드 담당자와 협업」이라고 적혀 있다. 전담 PM이 있는지는 못 찾음.
- 협업 도구: 못 찾음 (공고 자격요건에 Git 협업 경험이 있음).
- 의사결정 방식: 못 찾음 (마케팅 공고에는 「빠른 실행 문화와 자유로운 의견 제안 환경」이라고 적혀 있음).
- 온콜 · 운영 부담: 못 찾음. 다만 매일 대량의 데이터를 수집하는 서비스라 수집 파이프라인 운영이 개발팀의 일에 포함될 가능성이 높다(추정).
