## 리스크

- **재무 미확인**: DART 공시가 없고 매출 · 이익은 회사 주장뿐이다
- **잦은 방향 전환**: 공고 스스로 「3년간 8번의 피보팅」이라고 적었다. 스니핏은 2025-11 시작이라 제품 나이는 1년이다
- **아주 작은 조직**: 국민연금 8명 · 제품팀 7명이다. 한 명이 빠지면 영향이 크다
- **고용보험 인원과 실제 팀 크기 차이**: 고용보험 2명 · 국민연금 8명 · 제품팀 7명이 서로 맞지 않는다. 기준 시점이 달라서일 수 있다. 입사 시 4대보험 가입 형태를 확인할 것
- **공고를 자주 다시 올림**: 직행 기업정보 기준 최근 6개월 공고 26건(업계 평균 7.8건)이다. 마감된 공고 가운데 백엔드 개발자만 4건이다(#AI서버개발 · #최소5000 · #웹서비스개발 · #에이전트서버). 성장 채용인지 이탈인지는 자료로 가를 수 없다
- **무료 플랜 종료(2026-10-07)**: 사용자 수가 줄 수 있는 결정이다. 이후 유료 전환 성과는 못 찾음
- **플랫폼 의존**: 메타 광고 라이브러리 · 인스타그램 · 틱톡 · 유튜브 데이터를 모으는 사업이라 각 플랫폼의 정책 · 접근 제한이 바뀌면 영향을 받는다 (사업 구조에서 나온 판단, 실제 사건은 못 찾음)
- 구조조정 · 소송 · 규제: 못 찾음

신입 백엔드가 맡을 일 (공고 담당 업무)
- FastAPI 로 REST API · WebSocket 설계 · 개발
- Vector DB(Qdrant) 구축 · 최적화
- GPU · CPU · 분산 환경 AI 모델 서버 인프라 관리
- 대규모 영상 · 이미지 · 텍스트 수집 · 처리 파이프라인 설계
- Celery · RabbitMQ 비동기 작업 · 스케줄링
- LLM · 임베딩을 B2B 기능으로 만들고 고객 반응 확인

전형
- 서류 → 커피챗 → 「합 맞추기」 4일 실무 협업(급여 100% 지급) → 처우 협의

- 입사 뒤 수습 3개월 (급여 100%)
- 재학 중이면 이력서에 졸업 예정일을 반드시 적는다
