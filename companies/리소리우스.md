- 회사는 에이전트 · 모델 · 지식 그래프가 데이터를 정제하고, 필요한 단계에만 사람이 들어가는 방식을 지향한다고 밝혔다 (월간인물).
- 지금 열린 개발 공고 세 개(MLOps · Data Ingestion Engineer · ML Data Engineer)는 모두 데이터 · ML 인프라 직무다.
- 서버 · 백엔드 전용 공고는 없다.
- 데이터 엔지니어 두 공고의 본문은 거의 같다 (코호트 정의 · 데이터 분할 · 누수 검증 · Post-training 데이터).

MLOps 공고에서 신입이 맡게 될 일:

- GPU 학습 · 추론 인프라를 구축하고 운영한다.
- 실험 설정 · 데이터셋 · 체크포인트를 추적하는 실험 관리 환경을 만든다.
- LLM · 에이전트용 API 서빙과 배치 · 온라인 추론을 운영한다.
- SFT · 선호 학습 · RL 같은 Post-training 파이프라인을 만든다.
- 연구 코드를 재현 가능한 운영 시스템으로 옮긴다.
