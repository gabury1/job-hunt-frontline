## 리스크

- 영업적자가 해마다 커지고 있다 (2023년 -31억 원 → 2025년 -65억 원).
- 자본총계는 -131.7억 원으로 완전자본잠식 상태다 (2025년 말).
- 자본잠식의 대부분은 전환우선주(RCPS)가 회계상 부채(215억 원)로 잡힌 데서 생겼다. 이 금액을 자본으로 돌리면 자본은 약 +83억 원이 된다. 이 값은 직접 계산한 것이다.
- 단순 계산으로 현금 여력은 약 1.5년이다. 그래서 IPO가 늦어지거나 프리IPO 투자가 들어오지 않으면 자금을 다시 조달해야 할 수 있다.
- 상장은 기술성평가 통과가 전제다. 결과는 아직 확인되지 않았다.
- 구조조정 · 소송 · 규제 이슈는 못 찾음.
- 의료 데이터를 다루는 회사여서 보안 인증이 사업에 중요하다. 회사는 2025년에 ISO27001 · ISO27701 · HIPAA 인증을 받았다고 밝혔다(잡코리아 연혁).
- 리뷰에서는 경영진과 회사 운영에 대한 불만이 반복된다. 다만 리뷰가 2023년에서 멈춰 있다 (아래 참고).

**리뷰 요약**

- 총평: 평점 3.8에 리뷰는 8개뿐이고 추천율은 없다. 분포는 5점(50%)과 2~3점(50%)으로 갈린다. 블라인드지수 흐름은 공개 페이지에서 못 찾음. 리뷰가 10개 미만이어서 표본이 적고, 마지막 리뷰가 2023-12이어서 지금 회사를 보여 준다고 보기 어렵다.
- 장점
  - 워라밸이 가장 좋은 점으로 꼽힌다. 항목 점수는 4.6이고, 8개 중 5개가 5점을 줬다.
  - 구성원을 배려하고 복지를 챙긴다는 평가가 2022~2023년 초 리뷰에서 자주 나온다 (제목 8개 중 3개).
  - 비전이 명확하다는 평가도 한 건 있다.
- 단점
  - 경영진 점수가 3.0으로 가장 낮다. 8개 중 2개가 1점을 줬다.
  - 경영진의 운영 방식과 경직된 분위기를 지적하는 리뷰가 2023년에 몰려 있다 (제목 8개 중 3개).
  - 프로젝트가 설명 없이 취소됐다는 불만이 있다 (1개).
  - 긴축으로 연봉이 동결됐다는 이야기가 최신 리뷰에 나온다.
  - 커리어 향상은 3.3으로 두 번째로 낮다.
- 달라진 점 · 갈리는 점: 2022년 리뷰는 높은 점수와 전면 재택을 이야기한다. 2023년 하반기부터는 경영진에 대한 불만이 늘어난다. 지금 공고는 재택 대신 출근 기반 시차출퇴근을 적고 있다.

## 업무 방식 · R&R

**팀 구성**

- 팀 구성은 못 찾음.
- GitHub 소개에 「Medical ASR dev team」이 적혀 있다.
- 잡코리아 회사 소개는 「연구 중심의 조직 문화」를 내세운다.
- 공고의 근무환경 칸에는 「연구와 제품의 연결」이 적혀 있다.
- 병원 현장 운영은 별도 직무가 맡는 것으로 보인다. 근거는 같은 날 올라온 「의료 AI 솔루션 현장운영 담당자」 공고다.

**신입이 맡게 될 일 (공고 기준)**

- vLLM 기반 LLM 서빙 환경을 구축하고 운영한다.
- 양자화 · Tensor Parallel · GPU 메모리를 다루며 지연 시간과 처리량을 개선한다.
- 온프레미스 GPU 서버에 모델을 배포하는 과정을 자동화하고, 모델과 서빙 프레임워크의 버전을 관리한다.
- 오픈소스 LLM을 Fine-tuning하고, SFT · 강화학습 · Multi-GPU 분산 학습을 수행한다.
- FastAPI 등으로 LLM API · Serving API · 비즈니스 로직을 개발한다.
- Structured Output · Tool Calling · 비동기 동시 요청 처리를 개발한다.
- 서비스 로그를 보고 장애를 분석한다.
- 경력은 「무관」이지만 자격요건에 LLM 학습 경험과 vLLM 사용 경험이 들어 있다. 그래서 실제로는 경험자를 원하는 공고로 읽힌다.
