### 일하는 방식 (저장소에서 드러나는 것)

- CI: GitHub Actions에서 MySQL 8.4 서비스 컨테이너를 띄워 단위 테스트를 돌린다.
- CI는 Flyway 마이그레이션 파일 이름(버전 중복)도 PR 단계에서 검사한다.
- 설계 결정을 문서로 남긴다: `docs/ai-boundary.md` · `docs/decisions.md` · `docs/api-contract.md` · `PORTING_STATUS.md`.
