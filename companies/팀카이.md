## 업무 방식 · R&R

**팀 구성 (공고 직무 기준)**

| 직무 | 하는 일 |
|---|---|
| **Agent PM** | 고객사별 에이전트 사양 합의 · 응대율 · 처리율 지표를 FDE 와 함께 책임 |
| **Agent Engineer** | 여러 고객사가 쓰는 프레임워크 · 재사용 모듈(통합 패턴 · 테스트셋 · 가드레일) 개발. 「빌드의 80%가 자동으로 채워지는 추상화」가 목표 |
| **FDE** | 한 고객사의 에이전트 인스턴스 1개를 끝까지 구축하고 지표가 오를 때까지 현장 운영 |
| **Deployment Engineer** | 고객사 상담 채널 · CRM · 헬프데스크 · 인증 연동, 배포 · 모니터링 · 롤백 · 장애 대응 |
| **GTM · 콘텐츠 마케팅 · Data Specialist** | 영업 · 마케팅 · 데이터 |

**신입이 맡게 될 역할 (FDE 인턴 공고)**

- 정규직 FDE 와 짝을 지어 고객사 인스턴스의 한 모듈(특정 intent 처리 · 외부 API 연동 · 가드레일 룰)을 만든다
- 정규직 FDE 와 고객사 현장에 출장해 문의 유형 · 정책 · 예외 케이스 · 응대 톤을 익힌다
- 출시된 봇의 대화 로그를 매일 보고 실패 케이스를 태깅해 원인을 추정한다
- 빌드 절차 · 디버깅 방법을 사내 자산으로 정리한다
- 목표는 입사 6개월 안에 본인이 만든 모듈이 고객사 운영에서 돌아가는 것이다
- 전환형 인턴이고, 성장 경로는 FDE 인턴 → FDE 정규직 → Agent Engineer 정규직이다
- 신입이 지원할 수 있는 정규직 개발 공고는 Deployment Engineer(경력무관)다. FDE 정규직은 공고마다 경력 2~5년 · 0~20년으로 다르다
