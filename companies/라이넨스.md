## 업무 방식 · R&R

**팀 구성**
- 공고에는 「내부 개발팀」이 있다는 말만 나옵니다. 인원과 구성은 못 찾았습니다.

**맡게 될 역할 (공고 기준)**

| 단계 | 하는 일 |
|---|---|
| 문제 발견 | 직영 공장의 생산 · 품질 · 수배송 · 설비 과정을 직접 관찰하고, 공장장의 경험적 판단을 구조화한다 |
| 문제 정의 | 병목과 비효율을 데이터 · 시스템 문제로 다시 정의하고, 우선순위와 KPI를 정한다 |
| 구현 | 웹 도구 · 대시보드 · 자동화 워크플로 · AI Agent를 MVP로 빠르게 만든다 |
| 연동 | 운영 데이터 · 문서 · 센서 · 외부 시스템을 잇는 데이터 구조를 설계하고, 설비 · IoT · 비전과 연동한다 |
| 배포 · 운영 | 실제 공장에 배포한 뒤 사용률 · 생산성 · 오류율 · 납기 준수율을 모니터링한다 |
| 제품화 | 한 공장의 해결책을 다른 공장에도 쓸 수 있게 표준화하고, 제품 로드맵에 반영한다 |
