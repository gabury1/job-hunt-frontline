## 업무 방식 · R&R

### 팀 구성

- 채용 페이지의 부서: AI Research · AI Transformation · Algorithm · Application · Customer Solutions · Hardware · Software · System · System Software · Product · Productization Engineering · Solution QA · Operations 등.
- 직무별 조직에 가깝다. 하드웨어와 소프트웨어가 처음부터 한 팀으로 일한다는 것을 가치로 내건다.
- 서버 개발자가 갈 만한 팀은 둘이다.
  - AI Transformation 팀: 사내 엔지니어링 문제를 에이전트 시스템으로 자동화한다. Agent System Developer 공고 팀이다.
  - Platform 팀: 프로덕션 인프라의 신뢰성 · 확장성을 맡는다. SRE · Production Engineer(LLM Serving) 공고 팀이다.

### 신입이 맡게 될 일

- Agent System Developer: 에이전트 런타임(오케스트레이션 · 컨텍스트 관리 · 도구 실행 · 메모리 추상화) 구현, CLI · SDK 설계.
- 이 공고의 최소 자격은 네 항목 가운데 「두 개 이상」이다. Python 백엔드 + LLM 프로덕션 경험으로 맞출 여지가 있다.
- 고객은 사내 다른 조직이다. 하드웨어 설계 · 모델 최적화 팀과 협업한다.
- SRE: SLI · SLO 정의, 관측성 구축, 배포 · 용량 · 장애 복구 체계 개선.
- SRE 최소 자격에는 경력 연수가 없다.
- Production Engineer(LLM Serving)는 3년 이상을 요구해서 신입 대상이 아니다.
- Solution Architect (Junior)는 신입 대상이다. 고객사 PoC · 벤치마크 · 문서화를 맡는다. 서버 개발보다 기술 영업 지원에 가깝다.
