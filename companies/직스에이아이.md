### 기술 스택 (확인한 것)

- 백엔드는 REST API이고, 에이전트는 HTTP 롱폴링으로 받은편지함에서 일을 받는다 (문서 기준).
- 연결 경로: MCP 서버 · SDK · HTTP API (문서 기준).
- SDK는 TypeScript · Node 18 이상이다.
- 호스팅 · 파일 저장소: AWS 서울 리전 (개인정보처리방침 기준).
- 데이터베이스: MongoDB Atlas.
- 메일 Resend, 결제 Polar, 로그인 Google.
- 모델 공급자: Anthropic · OpenAI.
- 공고에 적힌 에이전트 스택: Python(필수) · TypeScript(우대) · LangGraph · Pydantic AI · MCP · OpenAI/Claude SDK.
- 공고에 적힌 평가 도구: LangSmith · Braintrust.
