  - 리뷰에서는 동료와 사람에 대한 만족이 가장 자주 나온다 (제목 6개 중 3개, 사내 문화 4.3).
  - 리뷰는 일과 삶의 균형이 지켜진다고 말한다 (4.3).
  - 리뷰는 배우고 커리어를 쌓을 것이 많다고 말한다 (커리어 향상 4.3).
  - 리뷰는 문화가 수평적이라고 말한다 (최신 리뷰 장점).
  - 회사 비전에 자부심을 느낀다는 리뷰가 있다 (2024 리뷰 제목).
- 단점
  - 리뷰는 경영진을 가장 약한 항목으로 꼽는다 (경영진 3.5, 2026년 리뷰 3개에서는 2~4점).
  - 리뷰는 경영진이 전하는 방향이 모호할 때가 있다고 말한다 (최신 리뷰).
  - 리뷰는 수익성 개선이 더디다고 말한다 (최신 리뷰).
  - 급여 · 복지 점수는 다른 항목보다 낮다 (3.8, 2026년 리뷰 3개 모두 3점).

**백엔드가 맡는 일 (Backend Engineer 공고, 경력 4~8년)**
- 하이퍼랩의 고도화와 신규 기능을 설계하고 개발한다.
- 오믹스호라이즌 · K-Fold 같은 LLM/AI 서비스를 유지보수하고 새 기능을 만든다.
- LLM Agent · RAG · 외부 AI 모델 · 비동기 작업을 제품 기능으로 연결한다.
- 연구 데이터 · 분석 결과 · 파일 · 워크플로 실행 이력을 저장하고 조회하는 API와 데이터 모델을 설계한다.
- CS · 기술 이슈를 분석하고, 재발을 막기 위한 개선과 자동화를 맡는다.
- PoC를 빠르게 제품으로 만드는 백엔드 구조를 설계한다.
- 백오피스를 개발한다.

**오늘 공고(AI Agent Engineer)가 맡는 일**
- 논문 분석 · 가설 수립 · 연구 코드 생성을 하는 멀티 에이전트를 만든다.
- 생성된 코드와 텍스트의 과학적 정합성을 자동으로 검증하는 워크플로를 만든다.
- 오믹스 데이터를 대화형으로 분석하는 에이전트를 만든다.
- 에이전트 워크플로를 기획 · 구현하고 제품으로 만든다.

**신입이 맡을 범위**
- 신입 백엔드 공고가 없어서 신입의 역할은 확인하지 못했다.
- 백엔드 공고가 운영 CS · 재발 방지까지 포함하므로, 입사하면 개발과 운영을 함께 맡을 가능성이 높다 (추정).
