> 공고에 적힌 「LG에릭슨」은 지금 법인 이름이 **주식회사 에릭슨코리아파트너스**(구 에릭슨엘지 주식회사)다. DART 감사보고서 머리에 「(구, 에릭슨엘지 주식회사)」로 적혀 있다.
> 직행이 「LG에릭슨」 이름 아래 에릭슨 전 세계 공고(청두 · 독일 · 사우디 등)를 함께 묶어 두었다. 아래는 한국 법인 기준이다.

## 한눈에

| 항목 | 내용 |
|---|---|
| 무엇을 하나 | 에릭슨 한국 법인. 통신사에 5G 무선망(RAN) · 패킷 코어 장비를 공급하고, 서울 R&D 에서 에릭슨 글로벌 제품을 개발 |
| B2B/B2C | B2B (고객은 SK텔레콤 · LG유플러스 같은 통신사) |
| 법인 | 주식회사 에릭슨코리아파트너스 (2025-03-01 에릭슨엘지에서 사명 변경) |
| 설립 | 2005-10-13 (DART 설립일, 엘지노텔로 시작) |
| 임직원 | 661명 (2026-04-01, 잡코리아) |
| 개발자 | 한국 R&D 센터 약 500명 (에릭슨 공식 페이지) |
| 본사 | 서울 강남구 강남대로 382 메리츠타워 (DART) |
| R&D 캠퍼스 | 서울 금천구 가산 LG 가산디지털센터 (에릭슨 한국 사이트 · 채용 자료) |
| 자회사 | 아이펙스 주식회사(IPECS, 구 에릭슨엘지엔터프라이즈) — 기업용 IP 전화 · UC 솔루션, 가산 LG가산디지털센터 11층 |

- 오늘 공고 셋 가운데 두 개(Packet Core · RAN Traffic Control)는 에릭슨 R&D 직무다.
- 「IPECS - Backend Developer」는 자회사 아이펙스 사업(iPECS) 직무다. 에릭슨 채용 사이트의 비슷한 iPECS 공고는 근무지를 가산으로 적는다. 고용 법인이 에릭슨코리아파트너스인지 아이펙스인지는 공고에서 확인하지 못했다.

## 성장

### 지분 · 연혁

- 2005: LG전자와 캐나다 노텔이 50%씩 투자해 엘지노텔 설립 (잡코리아 연혁)
- 2010-06: 에릭슨이 노텔 지분 50%를 사들여 LG-에릭슨으로 출범 (잡코리아 · 전자신문)
- 2012-09: 에릭슨이 LG전자 지분 25%를 더 취득, 사명을 에릭슨엘지로 변경 (잡코리아 연혁)
- 2013-11: 기업통신 사업을 물적분할해 에릭슨엘지엔터프라이즈(현 아이펙스) 설립 (잡코리아 · DART)
- 2025-03-01: LG 상표 계약 만료로 사명을 에릭슨코리아파트너스로 변경 (바이라인네트워크)
- 2025-04-01: 시벨 톰바즈 CEO 취임 (바이라인네트워크)
- LG전자가 지금도 지분을 갖고 있는지는 못 찾음 (2017년 자료 기준 에릭슨 75% · LG전자 25%)
- 외부 투자 유치 대상 회사가 아니다 (글로벌 기업의 한국 법인)

## 리스크

- 매출 감소: 2023 → 2025 매출이 4,353억 → 2,248억 원으로 거의 절반이 됐다. 국내 통신사 설비투자가 줄어든 시기와 겹친다 (디지털데일리 2026-09-01).
- 자회사 적자: IPECS 백엔드 공고의 사업인 아이펙스가 2025년 영업적자 40억 원을 냈다. 충당부채가 100억 원대로 늘어난 이유는 못 찾음.
- 본사 감원: 에릭슨은 2023년 글로벌 8,500명 감원에 이어 2026-01 스웨덴 1,600명 감원을 발표했다. 한국 법인 구조조정 보도는 못 찾음.
- 본사 의존: 해외 리뷰(Glassdoor · Indeed, 검색 결과 요약 기준)에 「본사 개입이 심하고 의사결정이 느리다」 · 「한국 관리자가 본사에 강하게 요구하지 못한다」는 말이 있다.
- 소송 · 규제: 못 찾음.

## 업무 방식 · R&R

- 팀 구성: 제품 단위 조직이다. 공고에 「PDU Packet Core」 · 「Packet Core Dev Korea」 · 「RAN Traffic Control」처럼 에릭슨 글로벌 제품 조직 이름이 붙는다.
- New Grads - Packet Core Developer: 5G AMF · 4G MME 같은 패킷 코어 소프트웨어 구성요소를 설계 · 개발 · 테스트한다 (리멤버의 같은 계열 공고). 시스템 아키텍트 · PM 과 요구사항을 맞추고, QA · 지원팀과 고객 이슈를 처리한다.
- Software developer | Early Career Program: RAN Traffic Control 개발에 더해 Research · Product Development · Data · AI 순환, 해외 배치, 멘토링이 붙는 프로그램이다. 이후 PM · Line Manager 경로가 열려 있다.
- IPECS - Backend Developer: MSA 백엔드 설계 · 구현, Kubernetes 운영, GitOps 배포, LLM · RAG 챗봇, MCP 인터페이스, 관측성 시스템까지 넓게 맡는다. 운영 책임이 큰 자리로 읽힌다.
- 기획자 · PM: 공고마다 프로덕트 매니저 · 시스템 아키텍트와의 협업이 적혀 있다. PM 이 있는 구조다.
- 협업 도구: Jira · Git (공고).
- 의사결정: 해외 리뷰 요약 기준으로 본사(스웨덴) 결정 비중이 크다. 위계형인지 자율형인지는 못 찾음.
- 온콜: 패킷 코어 · IPECS 모두 고객 이슈 대응이 공고에 있다. 온콜 제도는 못 찾음.
- 전형: Packet Core 는 서류 → 코딩 테스트 → 면접 2회 → 오퍼(4~8주). IPECS 는 리크루터 콜 → 코딩 테스트(Java · Python) → 직무 인터뷰 → 리더십 인터뷰.
- 영어: Early Career Program 은 영어 능숙도를 자격요건에 넣었다.
